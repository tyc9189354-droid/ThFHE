背景知識 (一) — LWE 晶格加密基礎與底層幾何數學難題

幾何晶格理論、SVP / SIVP / CVP 難題、Regev 最差至平均歸約、LWE/RLWE 加密與同態運算全剖析
1.1 幾何晶格基礎理論 (Lattice Geometry & Foundations) 幾何空間根基

在傳統數論密碼學（如 RSA、ECC）面臨量子 Shor 演算法多項式時間破解威脅的背景下，現代後量子與全同態密碼學全面建立於高維歐幾里得幾何晶格（Euclidean Lattice）之上。

  • 【工具定義：幾何晶格 (Lattice)】： 設 B = {b₁, b₂, …, bn} ⊂ ℝm 為一組由 n 個線性獨立的 m 維向量所組成的矩陣（稱為晶格的「基底」，m ≥ n）。由該基底生成的幾何晶格 Λ(B) 定義為全體整數線性組合構成的離散點陣空間：
    Λ(B) = { ∑i=1n xi · bi | xi ∈ ℤ } = { B · x | x ∈ ℤn }
    其中維度 n 稱為晶格的秩（Rank），當 m = n 時稱為滿秩晶格（Full-rank Lattice）。
  • 【基本並行多面體與晶格行列式】： 任一基底 B 圍成的半開半閉多胞體稱為基本並行多面體（Fundamental Parallelepiped）：
    𝒫(B) = { ∑i=1n ti · bi | 0 ≤ ti < 1, ti ∈ ℝ }
    該多胞體的體積在代數上等於基底矩陣的行列式絕對值，記為晶格行列式 det(Λ) = √det(BT · B)。 雖然同一晶格存在無窮多組不同的基底，但晶格行列式 det(Λ) 是晶格內在的不變量，幾何上反映了晶格點在空間中的全域平均分佈密度（點密度為 1 / det(Λ)）。
  • 【基底的非唯一性：好基底 vs. 壞基底】： 對於任何行列式為 ±1 的整數單模矩陣（Unimodular Matrix）U ∈ ℤn×n，新矩陣 B' = B · U 生成完全相同的晶格點陣 Λ(B') = Λ(B)。
    • 「好基底 (Reduced / Good Basis)」：向量長度短、彼此接近正交（正交度高）。持有好基底的使用者，可以利用 Babai 演算法以多項式時間求解高精度的空間最近點解碼（秘密金鑰）。
    • 「壞基底 (Ill-conditioned / Bad Basis)」：向量極其冗長、向量間夾角極小（接近平行）。面對壞基底，空間中哪怕僅加上微小的雜訊擾動，古典與量子計算機在幾何空間中都將陷入指數級的盲目搜索（公開金鑰）。
1.2 晶格上的四大核心數學難題 (Core Lattice Hardness Problems) 數學困難假設

所有晶格加密體系的安全安全性，均可嚴格數學歸約至以下四個歷經數十年密碼分析檢驗的幾何 NP 困難難題：

  • ① 最短向量問題 (SVP, Shortest Vector Problem)：
    • 【定義】：給定某晶格的一組任意隨機基底 B，在晶格中尋找一個非零晶格向量 v ∈ Λ (v ≠ 0)，使得其歐幾里得範數達到全域最小：
    ‖v‖ = λ₁(Λ) = minx ∈ Λ, x ≠ 0 ‖x‖
    其中 λ₁(Λ) 稱為晶格的第一逐次極小值（First Successive Minimum）。
    • 【近似版本 γ-SVP】：給定近似因子 γ ≥ 1，尋找非零向量 v ∈ Λ (v ≠ 0) 使得 ‖v‖ ≤ γ · λ₁(Λ)。 當 γ 是多項式階（γ = nc）時，目前已知最優演算法（如 LLL、BKZ 2.0、篩選法 Sieve）所需的時間複雜度均為指數級 2Ω(n)，甚至量子計算機亦無已知多項式時間解法！
  • ② 最短獨立向量問題 (SIVP, Shortest Independent Vectors Problem)：
    • 【定義】：給定晶格基底 B，尋找 n 個彼此線性獨立的晶格向量 {v₁, v₂, …, vn} ⊂ Λ，使得其中最長向量的長度最小化：
    max1 ≤ i ≤ n ‖vi‖ ≤ γ · λn(Λ)
    其中 λn(Λ) 為晶格的第 n 逐次極小值（容納 n 個獨立向量所需的最小半徑球）。
  • ③ 最近向量問題 (CVP, Closest Vector Problem) 與有界距離解碼 (BDD)：
    • 【定義】：給定晶格基底 B 與連續空間中任意一個目標向量 t ∈ ℝm，尋找晶格中距離該目標點幾何歐氏距離最近的晶格點 v ∈ Λ，使得 ‖t − v‖ = dist(t, Λ) = minx ∈ Λ ‖t − x‖。
    • 【有界距離解碼 (BDD, Bounded Distance Decoding)】：若保證目標點形式為 t = v + e，其中 v ∈ Λ 為真實晶格點，且誤差向量長度受限於 ‖e‖ < λ₁(Λ) / (2γ)，要求從 t 中解碼還原出原始晶格點 v。 LWE 的解密本質上就是 BDD 問題的密碼學實例！
  • ④ 判定性最短向量問題 (GapSVPγ)：
    • 【定義】：給定基底 B 與實數閾值 d > 0，判定晶格的最短非零向量長度是滿足 λ₁(Λ) ≤ d（YES 實例），還是滿足 λ₁(Λ) > γ · d（NO 實例）。在區間 (d, γ · d] 之間存在一個空隙（Gap），不保證任何輸入落於此處。
1.3 含錯學習問題 (LWE) 與 Regev 最差至平均歸約 (Search/Decision LWE & Reductions) 困難問題代數化

雖然幾何晶格難題極難，但直接使用幾何基底建構公鑰系統效率較低。Oded Regev 於 2005 年提出的含錯學習（LWE, Learning With Errors），成功將高維幾何晶格問題轉化為簡潔優雅的模線性代數方程組：

  • 【搜尋型 LWE (Search-LWE)】：
    • 【定義】：設正整數 n 為維度，q ≥ 2 為模數，χ 為有限體 ℤq 上的離散高斯分佈（標準差 σ = α · q，其中 α < 1）。 未知私鑰向量為 s ∈ ℤqn。演算法可以無限制地獲取隨機樣本 (ai, bi) ∈ ℤqn × ℤq，其中：
    ai ← ℤqn (均勻隨機採樣), ei ← χ (微小高斯隨機誤差)
    bi = ⟨ai, s⟩ + ei (mod q)
    【目標】：在多項式時間內從給定的 m 組樣本 (A ∈ ℤqm×n, b = A · s + e ∈ ℤqm) 中，100% 精確恢復出私鑰向量 s。
    • 【雜訊的魔力】：如果沒有雜訊（e = 0），利用高斯消去法在 O(n³) 步內即可輕易求出 s；但只要每個方程式加上極微小的高斯誤差 ei，模運算的週期性折疊會將高斯誤差急遽放大，使得任何古典與量子高斯消去法瞬間徹底破產！
  • 【判定型 LWE (Decision-LWE)】：
    • 【定義】：給定多組樣本對 (ai, bi)，要求演算法以不可忽略的優勢區分這兩組分佈：
    • 分佈 DLWE：真實的 LWE 樣本 (ai, bi = ⟨ai, s⟩ + ei mod q)。
    • 分佈 DRAND：純粹均勻隨機採樣的無關數值對 (ai, ui ← ℤq)。 在實用參數下，Decision-LWE 與 Search-LWE 具備多項式時間相互歸約等價性。
  • 【Regev 最差情況至平均情況量子歸約定理 (Worst-Case to Average-Case Reduction)】：
    Regev 證明了密碼學史上最堅固的理論保障： 「若存在任何多項式時間演算法，能在隨機生成的平均實例上攻破 Decision-LWE，則利用量子演算法，就能在最壞情況下解決任意 n 維幾何晶格上的 GapSVPγ 與 SIVPγ 難題（其中近似因子 γ = Õ(n / α)）！」
    這打破了傳統 RSA/ECC 只在特定「平均情況」構造下安全的限制——要破解 LWE，就必須能夠攻破整個幾何晶格空間中最極端、最難纏的病態實例！
1.4 環含錯學習 (RLWE) 與模含錯學習 (MLWE) (Algebraic Ring Generalizations) 代數多項式加速

標準 LWE 的向量矩陣乘法在實際應用中存在通訊與儲存膨脹的缺點（金鑰矩陣大小為 O(n²)）。為此，密碼學家發展了代數多項式擴展：

  • 【環含錯學習 (Ring-LWE / RLWE)】：
    • 【定義】：將向量空間壓縮至分圓多項式商環 Rq = ℤq[X]/(XN + 1)，其中維度 N = 2k（分圓多項式）。私鑰 s(X)、隨機多項式 a(X) 與誤差多項式 e(X) 均為該環中的多項式。樣本生成形式為：
    b(X) = a(X) · s(X) + e(X) (mod q)
    其困難度歸約至理想晶格（Ideal Lattices）上的最差情況 SVP/SIVP 難題。
    • 【優點】：密鑰與密文尺寸直接從 O(N²) 暴降至 O(N)；多項式乘法天然相容數論變換（NTT），速度提升數百倍。
    • 【缺點】：多項式環具備高度代數結構，若環維度或多項式選取不當，可能面臨代數子環攻擊。
  • 【模含錯學習 (Module-LWE / MLWE)】：
    • 【定義】：以多項式商環為基底的自由模 Rqk（多項式向量）。當模維度 k = 1 時退化為 RLWE，當多項式次數 N = 1 時退化為標準 LWE。
    • 【優點】：在標準 LWE 的保守安全性與 RLWE 的高效能之間取得完美平衡，已成為 NIST 後量子標準（如 ML-KEM / Kyber）的核心基礎。
  • 【廣義殘差數系環晶格 (RNS-GLWE)】：
    • 【定義】：當密文模數 Q 達到數百位元時，利用中國剩餘定理（CRT）將模數分解為多個符合現代 64-bit CPU 暫存器架構的小質數通道 Q = q₁ · q₂ · … · qr（各 qi < 2⁶⁰）。
    • 【優點】：徹底消除多倍精度大整數運算開銷，所有同態多項式運算在各小質數軌道間完全平行化獨立運算。
1.5 LWE / RLWE 加密機制與縮放因子 Δ (Encryption Scheme & Rounding Geometry) 密文結構與幾何捨入

在晶格加密中，明文與雜訊共享同一個數值空間。為了在解密時能將微小雜訊乾淨濾除，明文必須透過縮放因子放置在最高有效位：

  • 【工具定義：縮放因子 Δ】： 設明文空間為整數環 ℤp（明文 m ∈ {0, 1, …, p−1}），密文模數為 q（q ≫ p），縮放因子定義為：
    Δ = ⌊q / p⌉
    將明文訊息放大 Δ 倍推至最高位（MSB），而將加密高斯誤差 e 留在最低有效位（LSB）。
  • 【運作過程：LWE 對稱加密與解密】：
    ① 金鑰生成 (KeyGen)：隨機採樣私鑰向量 s ∈ ℤqn（通常係數為小整數或三元分佈 si ∈ {−1, 0, 1}）。
    ② 加密過程 (Encrypt)：輸入明文 m ∈ ℤp，隨機採樣基底向量 a ← ℤqn，採樣小高斯雜訊 e ← χ，計算：
    b = ⟨a, s⟩ + Δ · m + e (mod q)
    輸出密文為數值對 ct = (a, b) ∈ ℤqn × ℤq。
    ③ 解密過程 (Decrypt)：持有私鑰 s 者計算解密相位（Phase）：
    phase = b − ⟨a, s⟩ = (⟨a, s⟩ + Δ · m + e) − ⟨a, s⟩ = Δ · m + e (mod q)
    執行四捨五入除法還原明文：
    m = ⌊ phase / Δ ⌉ mod p = ⌊ (Δ · m + e) / Δ ⌉ mod p = ⌊ m + e / Δ ⌉ mod p
  • 【優點與缺點】：
    • 優點：解密僅涉及一次簡單的向量內積與純標量除法，演算法極為簡潔。
    • 缺點：嚴格要求解密正確性邊界 |e| < Δ / 2。一旦運算累積雜訊突破臨界點，捨入便會發生向相鄰明文格點的跳躍，產生解密錯誤。
🔢 具體算式範例：LWE 幾何捨入與解密濾除雜訊過程

設定密文模數 q = 64，明文空間 p = 4（明文 m ∈ {0, 1, 2, 3}）。
計算縮放因子：Δ = ⌊64 / 4⌉ = 16。容許的雜訊最大半徑為 Δ / 2 = 16 / 2 = 8。
設私鑰維度 n = 2，私鑰向量 s = (2, 3)。
欲加密明文 m = 2，採樣隨機基底 a = (5, 7)，採樣高斯雜訊 e = +3（3 < 8）。
1. 計算內積：⟨a, s⟩ = 5·2 + 7·3 = 10 + 21 = 31 (mod 64)。
2. 計算密文標量 b：b = ⟨a, s⟩ + Δ·m + e = 31 + 16·2 + 3 = 31 + 32 + 3 = 66 ≡ 2 (mod 64)。
密文為 ct = ((5, 7), 2)。
3. 解密端計算相位：phase = b − ⟨a, s⟩ = 2 − 31 = −29 ≡ 35 (mod 64)。
4. 捨入還原：m = ⌊35 / 16⌉ = ⌊2.1875⌉ = 2。明文 2 100% 精確還原，雜訊 3 被徹底消滅！

1.6 同態運算中的雜訊增長機制與重線性化技術 (Homomorphic Addition, Multiplication & RLK) 同態代數評估

同態加密允許在密文上直接評估加法與乘法電路，但不同運算的雜訊成長軌跡截然不同：

  • 【工具一：同態加法 (Homomorphic Addition)】：
    • 【運作過程】：設兩組密文為 ct₁ = (a₁, b₁) 與 ct₂ = (a₂, b₂)，伺服器直接計算：
    ctadd = (a₁ + a₂, b₁ + b₂) mod q
    解密相位為：
    phaseadd = (b₁ + b₂) − ⟨a₁ + a₂, s⟩ = Δ · (m₁ + m₂) + (e₁ + e₂) (mod q)

    • 【優點與缺點】：加法雜訊僅為線性疊加 eadd = e₁ + e₂，耗費雜訊預算微乎其微，可支援深層加法。
  • 【工具二：同態乘法與維度膨脹 (Homomorphic Multiplication)】：
    • 【運作過程】：兩密文相位直接交乘：
    phase₁ · phase₂ = (b₁ − ⟨a₁, s⟩) · (b₂ − ⟨a₂, s⟩) = Δ² · (m₁ · m₂) + Δ · (m₁e₂ + m₂e₁) + e₁e₂
    展開後出現了私鑰的二次交叉項 s ⊗ s，密文維度膨脹為 3 元素向量 (c₀, c₁, c₂)，其解密式變為：
    c₀ + ⟨c₁, s⟩ + ⟨c₂, s ⊗ s⟩ = Δ² · m₁m₂ + 雜訊 (mod q)
  • 【工具三：重線性化金鑰 (Relinearization Key, RLK) 降維】：
    • 【工具定義】：為了將 3-term 密文還原回標準的 2-term 密文，金鑰生成者發布評估輔助公鑰 RLK，將私鑰二次項偽裝加密：
    RLK = (arlk, brlk = arlk · s + P · s² + erlk) mod P·q
    其中 P 為輔助大模數。
    • 【運作過程】：雲端伺服器計算 c₂ · RLK 並除以 P 縮放，將二次項 s² 投影替換消除，強行壓回標準 2 元素密文。
    • 【優缺點】：重線性化成功鎖定維度不至發散；缺點是會引入額外的重線性化高斯誤差，且乘法雜訊大幅增長。
🔢 具體算式範例：同態加法線性雜訊 vs. 同態乘法二次雜訊對比

設初始雜訊 e₁ = 2, e₂ = 3，明文 m₁ = 1, m₂ = 2，縮放因子 Δ = 100。
• 同態加法：新雜訊 eadd = 2 + 3 = 5。雜訊僅增加 3，佔比極低。
• 同態乘法：交乘雜訊展開式為：
Δ · (m₁e₂ + m₂e₁) + e₁e₂ = 100 · (1·3 + 2·2) + 2·3 = 100 · 7 + 6 = 706。
經模數縮放（除以 Δ = 100）還原後，殘存雜訊約為 706 / 100 = 7.06。
單次乘法使雜訊增幅超過 350%，這直觀展示了為何全同態加密的深度受到乘法層數的極大制約。

1.7 雜訊控制兩大機制：TFHE 盲旋轉自舉 vs. RNS-NTT 批次模數鏈 雜訊管理工程
  • 【機制 A：TFHE 盲旋轉自舉 (Blind Rotation Bootstrapping)】：
    • 【定義】：在小模數下，當雜訊逼近臨界值時，利用密文相位作為單項多項式 X−phase 的指數，以同態方式在環中旋轉預設的查表多項式（LUT）。
    • 【運作過程】：在密文域內同態執行非線性符號函數與解密線路，直接產出一份包含相同明文、但雜訊被重置為全新小高斯雜訊的新密文。
    • 【優點與缺點】：能達成無窮深度的任意布林閘運算；缺點是每次自舉需要數毫秒計算，開銷較大。
  • 【機制 B：RNS 模數切換與 NTT 卷積 (Modulus Switching & NTT)】：
    • 【定義】：使用數百位元的階梯式模數鏈 Q = q₁ · q₂ · … · qL。每執行一層同態乘法，直接將密文除以一個質數通道（Rescaling），將乘法帶來的膨脹雜訊等比例縮小。
    • 【運作過程】：配合數論變換（NTT），在各質數通道上將多項式卷積複雜度由 O(N²) 降至 O(N log N)。
    • 【優點與缺點】：支援高吞吐量 SIMD 向量批次打包計算；缺點是乘法深度有限，當模數鏈耗盡後便無法繼續計算。

2.1 門檻秘密分享的核心理念與幾何分割 (Philosophy of Secret Sharing) 金鑰分散本質

在傳統集中式密碼系統中，私鑰 s 由單一伺服器持有，面臨單點入侵、權限濫用或實體硬碟毀損的不可逆風險。 門檻秘密分享技術將原始秘密 s 拆解為 N 份彼此獨立的「秘密份額（Shares）」s₁, s₂, …, sN，發放給各參與節點。唯有達到門檻數量的節點協同合作方能還原秘密或完成解密，任何低於門檻數量的勾結均在數學上完全無法獲得秘密的任何資訊。

2.2 工具一：全門檻加法秘密分享 (Additive Secret Sharing / N-of-N) 全門檻與不誠實多數
  • 【工具定義】： 在整數環 ℤQ 上，秘密 s 被拆分為 N 個份額，滿足代數和關係：
    s = ∑i=1N si (mod Q)
  • 【運作過程】：
    ① 份額分發：前 N−1 個節點的份額隨機均勻獨立採樣 si ← ℤQ；第 N 個節點的份額計算為：
    sN = s − ∑i=1N−1 si (mod Q)

    ② 協同部分解密：各節點使用手上的本地份額 si 計算部分解密值 pi = ⟨a, si⟩ mod Q。
    ③ 聚合重構：聚合器將所有收到的部分解密值直接相加：
    P = ∑i=1N pi = ∑i=1N ⟨a, si⟩ = ⟨a, ∑i=1N si⟩ = ⟨a, s⟩ (mod Q)
  • 【優點與缺點】：
    • 優點：達成不誠實多數（Anytrust / N−1 容錯），即使 N−1 人全部勾結，其視圖在資訊理論上依然與均勻隨機不可區分；且重構僅需純加法，通訊開銷為 0。
    • 缺點：零容錯性（0-Fault Tolerance）。任一節點離線或惡意發布錯誤數值，解密即告中斷。
🔢 具體算式範例：3-of-3 加法分享與完美隱匿證明

設模數 Q = 100，秘密 s = 42，節點數 N = 3。
1. 隨機採樣份額：s₁ = 73, s₂ = 85。
2. 計算最後一份額：s₃ = 42 − (73 + 85) = 42 − 158 = −116 ≡ 84 (mod 100)。
3. 驗算求和：s₁ + s₂ + s₃ = 73 + 85 + 84 = 242 ≡ 42 (mod 100)。
敵手勾結分析：假設節點 1 與節點 2 串通，他們持有的份額和為 73 + 85 = 58。 對於任何未知的候選秘密 s' ∈ {0, 1, …, 99}，都唯一存在一個合法的 s'₃ = s' − 58 mod 100。因為誠實節點 3 的份額是全域均勻抽樣的，敵手猜測任何一個秘密的機率完全均等為 1/100，獲得的資訊增益精確為 0。

2.3 工具二：有限體 Shamir 門檻秘密分享與本地 Lagrange 轉換 (T-of-N Shamir Sharing) 容錯門檻與多項式插值
  • 【工具定義】： 在質數有限體 ℤq 上，構造一個次數為 T−1 的隨機多項式，其常數項被鎖定為真實秘密 f(0) = s：
    f(X) = s + a₁ · X + a₂ · X² + … + aT−1 · XT−1 (mod q)
    其中係數 a₁, …, aT−1 ← ℤq 均勻獨立抽樣。
  • 【運作過程：Lagrange 插值與本地乘算轉換】：
    ① 份額發放：第 i 位參與者獲得多項式在非零點 X = i 處的點值 si = f(i) mod q。
    ② Lagrange 插值定理：任意選取在線的 T 位節點集合 S ⊆ {1, 2, …, N}，常數項可精確還原：
    s = f(0) = ∑i∈S λi,S · si (mod q), 其中 λi,S = ∏j∈S, j≠i (−j) · (i − j)−1 (mod q)

    ③ 本地免通訊轉換：由於 Lagrange 係數 λi,S 僅依賴於公開的在線成員編號集合 S，在線節點 i 可在本地預先將私鑰份額轉換為 s'i = λi,S · si mod q。 部分解密提交 p'i = ⟨a, s'i⟩ 後，聚合器依然只需執行純加法求和，通訊複雜度維持常數項 O(1)！
  • 【優點與缺點】：
    • 優點：靈活容錯，允許最多 N − T 個節點當機離線；少於 T 個節點勾結絕對無法獲得任何秘密。
    • 缺點：嚴格要求底層模數 q 必須為質數（保證 (i − j) 必然存在乘法反元素）。
🔢 具體算式範例：3-of-5 Shamir 分享在 ℤ₁₉ 上的精確重構演算法

在有限體 ℤ₁₉ 上，秘密 s = 7，門檻 T = 3。
隨機選取 2 次多項式：f(X) = 7 + 2X + 3X² (mod 19)。
份額點值為：s₁ = f(1) = 12，s₄ = f(4) = 63 ≡ 6，s₅ = f(5) = 92 ≡ 16 (mod 19)。
假設節點集合 S = {1, 4, 5} 進行重構：
計算節點 1 之插值係數：
λ₁ = [(0−4)·(0−5)] / [(1−4)·(1−5)] = 20 / [(−3)·(−4)] = 20 / 12 ≡ 1 / 12 = 12−1 (mod 19)。
由於 12 · 8 = 96 = 5·19 + 1 ≡ 1 (mod 19)，故 12−1 ≡ 8 ⟹ λ₁ = 8。
同理計算：λ₄ = 12，λ₅ = 0（在模 19 下各乘積計算）。

2.4 工具三：Galois 環 GR(2K, d) Shamir 分享與 Reed-Solomon 糾錯 (Error-Correcting Sharing) 非質數環與主動容錯
  • 【工具定義：Galois 環擴張 GR(2K, d)】： 在許多同態架構中，模數為 2 的冪次 2K（例如 2⁶⁴, 2¹²⁸）。在該環中，偶數皆為零因子，插值分母 (i − j) 若為偶數則無反元素，Shamir 插值直接崩潰。 為此構造多項式商環 GR(2K, d) = ℤ2K[X] / (F(X))，其中 F(X) 在模 2 商體 GF(2d) 上本原不可約。 在商體中選取非零互異元素作為評價點，保證在 Galois 環中差值必為可逆的單位元素（Unit）。
  • 【運作過程：Reed-Solomon 糾錯碼 (Robust Reconstruction)】：
    ① 各節點在 Galois 環中提交部分解密點值 (i, pi)。
    ② 當惡意節點提交竄改的假數值時，解密中心將收到的 N 個點值視為帶有雜訊的 Reed-Solomon 碼字。
    ③ 調用糾錯解碼演算法（如 Berlekamp-Massey 或 Welch-Berlekamp 演算法）。 只要惡意節點數量滿足 t < N / 3，演算法能自動定位出惡意節點的編號，並在代數上將錯誤數值修正，成功解碼出真實多項式常數項！
  • 【優點與缺點】：
    • 優點：相容 2 的冪次模數；在惡意攻擊下協議不中斷，達成保證輸出遞送（Guaranteed Output Delivery, GOD）。
    • 缺點：需要 Galois 環代數擴展，糾錯解碼演算法複雜度為 O(N · log² N)。

3.1 門檻解密的致命破口：為什麼雜訊洩漏等於私鑰洩漏？ (The Fatal Leakage Vulnerability) 核心破口分析

在門檻全同態系統中，各節點持有私鑰份額 si。 若採用天真的樸素門檻解密：各節點發布 pi = ⟨a, si⟩ (mod q)，聚合器相加得到 P = ⟨a, s⟩ 並計算 phase = b − P = Δ · m + e (mod q)，捨入得到明文 m。 這會立即暴露出最終密文的真實加密雜訊 e 的具體數值！

  • 【線性方程組攻擊原理 (Linear System Attack)】： 在同態運算中，密文雜訊是加乘電路的展開式。在無模數意義下，最終雜訊可展開為：
    e = ∑ kj · einit, j + ⟨α, s⟩
    其中係數向量 α 完全由公開的電路拓樸決定。 攻擊者只要發送 k 組測試密文請求解密，記錄每次洩漏的誤差值 e(1), e(2), …, e(k)，就能列出包含 n 個未知數的無模數線性方程組。利用高斯消去法在數微秒內即可完全解出私鑰向量 s！
🔢 具體算式範例：高斯消去法攻破無防護門檻解密

假設未知私鑰為 3 維向量 s = (s₁, s₂, s₃) = (2, −1, 3)。
攻擊者挑選 3 組已知明文為 0 的測試密文發起解密，側錄到殘餘雜訊：
• 查詢 1：送出 a(1) = (1, 2, 1) ⟹ 洩漏雜訊 e(1) = 1·(2) + 2·(−1) + 1·(3) = 3。
• 查詢 2：送出 a(2) = (2, 1, 0) ⟹ 洩漏雜訊 e(2) = 2·(2) + 1·(−1) + 0·(3) = 3。
• 查詢 3：送出 a(3) = (0, 3, 1) ⟹ 洩漏雜訊 e(3) = 0·(2) + 3·(−1) + 1·(3) = 0。
直接列出三元一次方程組：
① s₁ + 2·s₂ + s₃ = 3；② 2·s₁ + s₂ = 3；③ 3·s₂ + s₃ = 0。
由 ③ 得 s₃ = −3·s₂，代入 ① 得 s₁ − s₂ = 3，聯立 ② 解得：
s₁ = 2, s₂ = −1, s₃ = 3！僅需 3 次解密請求，整組私鑰無所遁形。

3.2 工具一：統計雜訊淹沒 (Noise Flooding / Smudging) 流派一：統計隱匿
  • 【工具定義】： 在各節點發布部分解密時，人為疊加一個巨額均勻隨機雜訊 Eflood ∈ [−Bflood, +Bflood]。 若原始雜訊上界為 B，設定 Bflood ≥ 2λ · B（λ 為統計安全參數，通常取 40 或 80）。
  • 【運作過程】：
    ① 各節點計算加噪部分解密：pi = ⟨a, si⟩ + Eflood, i mod q。
    ② 聚合器求和：phase = b − ∑ pi = Δ · m + e + ∑ Eflood, i mod q。
    ③ 根據 Smudging 引理，真實雜訊 e 與被淹沒後的總雜訊之間的統計距離滿足：
    SD(Eflood, e + Eflood) ≤ B / Bflood ≤ 2−λ
    在統計學上，敵手觀察到的殘存雜訊與純隨機均勻雜訊不可區分，私鑰相關項被徹底遮蔽。
  • 【優點與缺點】：
    • 優點：單輪非交互發布，實作極為簡約，安全證明直觀。
    • 缺點：密文模數 q 必須相應擴大 λ 個 bits（40~80 bits）以包容洪水雜訊，造成密文尺寸與多項式運算時間增加。
🔢 具體算式範例：Smudging 雜訊淹沒之模數擴展計算

設原始密文雜訊上界 B = 2¹⁰ = 1024，統計安全參數 λ = 40。
淹沒半徑：Bflood = 2⁴⁰ · 1024 = 2⁵⁰。
若明文空間 p = 4（佔 2 bits），為確保捨入不溢位（Bflood < Δ / 2 = q / (2·p) = q / 8），密文模數必須滿足：
q > 8 · Bflood = 2³ · 2⁵⁰ = 2⁵³。 原本單方加密只需 20 位元的計算，門檻統計淹沒要求模數至少提升至 53 位元。

3.3 工具二：無淹沒 MPC 協同捨入 (MPC Rounding via ℱABB) 流派二：閉門消噪

  • 【運作過程】：
    ① 各節點在黑盒內輸入私鑰份額，計算秘密分享狀態下的相位：[phase] = [b] − ⟨a, [s]⟩。

    低位的微小雜訊在秘密內部被精確截斷消除。
    ③ 各方僅廣播重構那個已經完全除盡、毫無雜訊殘留的明文 m。
  • 【優點與缺點】：
    • 優點：零模數膨脹（Zero Modulus Growth），直接採用現代處理器原生 32/64-bit 模數，並天然相容可調適通用可組合（UC）模擬安全。

3.4 工具三：伺服器縮模與常數方差雜訊填充 (Server Rescaling & Noise Padding) 流派三：範數常數化

    Var(etotal) = Var(e) + Var(ζ) = Bpub² (公開常數)

    ① Round 1 (Masked Opening)：各方廣播被均勻隨機遮罩保護的數值：
    v = (b − ⟨a, s⟩ + r) mod η
    由於 r 全環隨機，數值 v 不洩漏任何私鑰資訊；在此階段直接拔除低位雜訊。
    ② Round 2 (Unmasking)：各方廣播第二環遮罩 ⟨r⟩Φ，聚合器相減後直接取得乾淨的放大明文 Φ · m，除以常數 Φ 即完成解密。
  • 【優點與缺點】：
    • 優點：無模數膨脹，通訊極短（每方僅 100~128 bits），達到亞毫秒級速度。
    • 缺點：需要 2 輪線上通訊。

• 作弊竄改場景：若惡意節點發布竄改後的份額 sh' = 38（偏移了 10）：
驗證端檢驗：u·z − ch·sh' = 189 − 3·38 = 189 − 114 = 75 ≠ 4 (mod 101)！ 等式破裂，作弊行為當場被系統揪出！

4.3 工具二：Ajtai 雜湊承諾與無繞回商數檢查 (Ajtai Commitments & No-Wrap Checks) 跨環代數約束
  • 【工具定義】： 在小明文空間 ℤp 上註冊私鑰的 Ajtai 雜湊承諾：C = A · s + e (mod p)。 基於最短整數解難題（SIS），具備嚴格的計算綁定性（Binding）與隱匿性（Hiding）。
  • 【運作過程：跨 RNS 通道無繞回商數約束】：
    ① 當私鑰被延伸至大模數 RNS 的各個大質數通道 qj 時，為了防止惡意節點在各通道發布彼此矛盾的偽造私鑰，構造多項式整除商數約束：
    sqj = sp + p · kj, 約束商數範數 ‖kj‖∞ ≪ qj
    保證私鑰跨通道轉換時無整數繞回溢位（No-wrap），在代數上等價鎖定全域唯一性。
    ② 消滅 Knowledge Gap (零鬆弛三元分解)：利用多項式恆等式 x · (x − 1) · (x + 1) = 0，在零知識證明中精確鎖死私鑰係數只能在 {−1, 0, 1} 之中，杜絕超額私鑰矇混過關。
  • 【優點與缺點】：
    • 優點：零代數鬆弛，可跨多條質數通道鎖定一致性。
    • 缺點：需要對多個多項式進行零知識評估，若逐一驗證複雜度為線性 O(N)。
4.4 工具三：基準質數投影商數證明與 BFS 二分批次快篩 (Base-Prime BFS Batch Verification) 極速批次抓鬼演算法
  • 【工具定義】： 將完整大模數 Q 上的同態商數驗證公式，全數降維投射至單一 60-bit 基準質數通道 KQ = q₁；並設計基於佇列的廣度優先搜尋（BFS）二分批次檢驗演算法。
  • 【運作過程】：
    ① 基準質數投影證明：證明者只需針對單一 60-bit 基準質數構造同態商數方程與範數邊界約束 ‖Zs‖∞ ≤ KQ / 4，證明尺寸縮減 75% 以上。
    ② 全員誠實場景 (O(1) 常數時間)：驗證端將全體 N 個節點的同態證明線性求和，只執行 1 次整體同態驗證！若通過，整體開銷僅為 O(1)。
    ③ 遭受攻擊場景 (O(log N) 樹狀快篩)：若總體檢驗失敗，驗證器啟動 BFS 佇列將節點二分切半：誠實半邊一次通過，含作弊者的半邊持續二分，在 O(log N) 輪內鎖定並剔除所有作弊者。
  • 【優點與缺點】：
    • 優點：常態下驗證延遲幾乎為零；少數惡意作弊時可在對數輪內快速抓鬼，徹底破除線性瓶頸。
    • 缺點：若超過半數節點同時作弊，二分樹退化為遍歷。

背景知識 (五) — 威脅模型與正式安全概念：CPAD、FuncCPA 與 UC 安全

配合架構與流程圖解，深入解析半誠實與不誠實多數界限、解密預言機探測防禦、電路隱私與通用可組合 UC 模擬安全
5.1 敵手威脅模型全景矩陣 (Threat Models & Corruption Boundaries) 信任邊界劃分

在分散式密碼學中，威脅模型定義了系統能夠抵禦何種能力的敵手。以下圖解直觀展示了「行為模式（半誠實 vs. 主動惡意）」與「容錯門檻（誠實多數 vs. 不誠實多數）」兩大維度所構成的四大象限：

  • 【半誠實敵手 (Semi-Honest / Passive)】：敵手嚴格按照規定的演算法執行運算，只在暗地裡記錄並分析所有接收到的封包試圖破解隱私。防禦主要依賴代數隨機遮罩與秘密分享。
  • 【主動惡意敵手 (Active / Byzantine)】：敵手可任意竄改本地程式碼、發送畸形金鑰或假份額。防禦必須依賴零知識證明（ZKP）或訊息驗證碼（MAC）。
  • 【誠實多數 (Honest Majority)】：假設全體節點中超過半數（t < N/2，或拜占庭容錯中的 t < N/3）是完全誠實者。
  • 【不誠實多數 (Dishonest Majority / Anytrust: t = N − 1)】： 密碼學的黃金最高標準！允許全體 N 個節點中有高達 N−1 個節點被敵手入侵並串謀勾結！ 全系統只要還存在 最後 1 位誠實節點，敵手就絕對無法破解任何密文或獲取金鑰；一旦發現作弊立即中止（Abort on Cheating）。
5.2 CPAD 安全概念：選擇明文與解密預言機攻擊 (CPA with Decryption Queries) 解密預言機防護

在單方公鑰加密中，標準的 IND-CPA 遊戲嚴格禁止敵手接觸「解密伺服器」。 但在分散式門檻系統中，任何合法使用者都有權限發送密文請求門檻解密——如果敵手偽裝成使用者，刻意構造畸形密文，系統就直接向敵手開放了「解密預言機（Decryption Oracle）」：

  • 【工具概念定義：CPAD 安全性】： 要求門檻解密系統在面對擁有「解密預言機訪問權限」的敵手時，預言機回傳的任何數值（包含殘餘雜訊與成功/失敗狀態）在條件機率分佈上與私鑰向量 s 嚴格統計獨立（Statistical Independence）。
  • 【運作過程：臨界探測攻擊與防禦】：
    ① 攻擊流程：敵手將密文雜訊調整至臨界邊界 Δ/2 − ε。若未防護，捨入溢位機率與私鑰正負號微幅相關，敵手每次詢問穩定榨取 1 位元私鑰符號。
    ② 防禦流程：門檻解密端在發布結果前，注入比原始雜訊大 2λ 倍的統計洪水雜訊（Smudging），或在 MPC 算術黑盒內部直接完成捨入截斷，使回傳分佈與私鑰的統計距離滿足 SD ≤ 2−λ，徹底截斷探測通道！
  • 【優點與缺點】：
    • 優點：徹底封死主動探測私鑰的側信道。
    • 缺點：需要額外增加模數寬裕空間或採用 MPC 查表輪數。

5.3 IND-FuncCPA：電路隱私與專利演算法保護 (Circuit Privacy) 計算拓樸保護

在雲端機器學習推論服務中，伺服器投入了高昂研發成本構建神經網路模型。電路隱私保證解密端無法反向推導出伺服器的模型結構：

  • 【工具概念定義：IND-FuncCPA】： 計算後的同態密文在解密時，其所揭示的所有訊息僅取決於最終運算結果 f(m)，而在數學上完全抹除有關評估電路 C 的拓樸結構、乘法層數與模型權重痕跡。
  • 【運作過程：零密文重隨機化 (Re-randomization via czero)】：
    ① 同態運算結束後，密文內部的雜訊包含了電路計算的痕跡。
    ② 伺服器使用集體公鑰全新加密一個數值為 0 的新鮮密文：czero = Enc(PK, 0; efresh)。
    ③ 將零密文同態疊加至運算密文上並注入適量淹沒雜訊，將舊雜訊特徵完全重設，達成與原電路完全無關的標準高斯分佈。
  • 【優點與缺點】：
    • 優點：百分之百保護伺服器專利模型不被逆向工程。
    • 缺點：需要在評估最後增加一次零密文加密與同態加法運算。
5.4 通用可組合性 (Universal Composability, UC) 與理想功能模擬 全域模組安全

由 Ran Canetti 提出的通用可組合（UC）框架，保證了密碼協議作為子模組嵌入到更龐大的區塊鏈、跨鏈橋或 MPC 系統中時，依然絕對安全不破防：

  • 【工具概念定義：UC 模擬安全】： 若對於任何在真實世界中攻擊協議 π 的敵手 𝒜，都存在一個在理想世界中運行的多項式時間模擬器 Sim，使得任何外部環境實體 𝒵 都無法區分自己是在與真實世界還是在與理想世界交互，則稱協議 π 具備 UC 安全性。
  • 【運作過程：理想功能 ℱABB 與模擬器視圖偽造】：
    ① 理想功能 ℱABB：假設存在絕對安全的中立黑盒，各方將輸入送入黑盒，黑盒計算後輸出明文。
    ② 模擬器 Sim 的核心任務：Sim 在完全不知曉誠實節點私鑰的前提下，僅憑理想功能給出的輸出結果，利用隨機雜訊與假私鑰偽造出一組真假難辨的網路通訊視圖。
    ③ 由於協議具備雜訊淹沒或 MPC 查表消噪，環境實體 𝒵 觀察到的真實視圖與假視圖統計不可區分，證明真實協議達到理想黑盒等級的安全。
  • 【優點與缺點】：
    • 優點：具備任意並行嵌套的可組合性保證，是現代密碼學的最高榮譽標準。
    • 缺點：嚴格的 UC 證明通常要求共用隨機字串（CRS）或預處理設置。

6.1 密碼學系統評測的核心理念：同軌公平基準 (Fair Apples-to-Apples Evaluation) 基準評測哲學

在分散式同態密碼學領域，評估一套方案的優劣不能僅看單一維度： 有些演算法單機運算極快，但線上通訊需要多輪來回握手，在廣域網路（WAN）下延遲暴增；有些方案在半誠實環境下表現優異，但加入主動防禦的零知識證明後計算開銷激增百倍。 同軌公平基準（Apples-to-Apples Evaluation）將運算延遲、通訊輪數、頻寬開銷與安全良率置於統一控制變因下進行多維度綜合檢驗。

6.2 全域實驗控制參數深度解析 (Benchmark Control Parameters) 控制變因解析
  • 【參數一：參與方總數量 (N = 10 ~ 1000)】：
    • 定義與考驗目標：參與分散式金鑰分發與門檻解密的實體總數。主要考驗演算法的時間與空間擴展性（Scalability）。
    • 擴展性層級：常數複雜度 O(1)（Shamir 分享份額固定）、對數複雜度 O(log N)（二分批次快篩）、線性複雜度 O(N)（逐一 ZKP 驗證）。
  • 【參數二：隨機惡意節點比例 (0% ~ 49%)】：
    • 定義與考驗目標：系統中遭受敵手入侵並主動發動作弊的節點百分比（最高近半數節點腐敗）。
    • 檢驗重點：半誠實方案在作弊注入時是否發生明文損毀，以及主動防禦方案是否能做到 100% 成功攔截並剃除作弊節點。
  • 【參數三：四大代表性主動攻擊模式 (Attack Scenarios)】：
    ① 超標雜訊淹沒攻擊 (Excessive Noise)：注入大於容許上界的雜訊，企圖突破臨界邊界 Δ/2 製造解密進位溢位。
    ② 非三元畸形私鑰攻擊 (Malformed Key)：金鑰係數超出 {−1, 0, 1} 約束，檢驗範數約束機制。
    ③ 解密份額與 MAC 竄改攻擊 (Corrupted Share)：惡意偏移部分解密數值，企圖污染最終輸出明文。
    ④ 聚合伺服器欺詐 (Equivocating Aggregator)：中心伺服器向不同成員發布相斥的多項式視圖。
  • 【參數四：明文空間大小 (T ∈ {2, 16, 256, 1024})】：
    • 定義與考驗目標：明文數值空間容量。縮放步距為 Δ = ⌊Q / T⌉。
    • 極限挑戰：當 T 由 2 擴展至 1024 時，格點安全間距縮小 512 倍，極度考驗演算法在雜訊控制與模數精度間的餘裕設計。
6.3 七大計時實測階段全流程剖析 (The 7 Benchmark Stages) 端到端計時鏈
  • Stage 1: Setup（公開參數初始化與預處理）：生成共用隨機字串（CRS）、RNS 質數基線通道、以及 MPC 查表所需的三元組。
  • Stage 2: KeyGen（門檻分散式金鑰生成）：協同生成私鑰份額、集體公鑰 PK、重線性化金鑰 RLK、以及 ZKP 註冊承諾。
  • Stage 3: Encrypt（明文編碼與密文注入）：將輸入數值乘以 Δ，注入初始高斯雜訊，生成標準密文 ct = (a, b)。
  • Stage 4: Eval (Add/Mul)（同態運算與電路評估）：在密文上執行同態加乘與重線性化，測試密文運算吞吐量。
  • Stage 5: PartDec（本地部分解密與雜訊處理）：各節點計算內積相位，並執行統計雜訊淹沒、MPC 內部捨入或雙環遮罩。
  • Stage 6: ZKP/MAC Verify（主動防禦驗證與抓鬼篩檢）：驗證 Fiat-Shamir NIZK、檢查 MAC 標籤或執行 BFS 二分快篩抓出作弊節點。
  • Stage 7: Combine（最終明文聚合與解密輸出）：收集合法份額求和或插值，捨入還原明文並檢驗結果正確性。
