基礎知識閱讀 (導讀) — 密碼學範式轉移與底層知識地圖

0.1 傳統公鑰密碼學的黃金時代與致命盲點 (RSA / ECC vs. Shor 演算法) 歷史演進脈絡

二十世紀後半葉建立的經典公鑰密碼體系（如 RSA、Diffie-Hellman 金鑰交換、ECDSA 橢圓曲線簽章），其安全性依賴於整數質因數分解問題（IFP）或有限體/橢圓曲線上的離散對數問題（DLP / ECDLP）。 在抽象代數結構上，這些密碼系統均運作於有限阿貝爾群（Finite Abelian Group）之上。

  • 【代數週期性與隱子群難題 (Hidden Subgroup Problem, HSP)】： 有限阿貝爾群本質上具備強烈的全域週期代數結構。例如在 RSA 模數 N = p · q 下，由歐拉定理可知 aφ(N) ≡ 1 (mod N)，其冪次映射序列必然呈現固定週期 r（且 r | φ(N)）。破譯 RSA 等價於尋找該週期 r。
  • 【彼得·秀爾量子演算法 (Shor's Algorithm, 1994) 的降維打擊】： 傳統經典電腦尋找群週期只能依靠枚舉或數體篩法（Number Field Sieve），開銷達次指數級 exp(O((log N)1/3))； 然而，量子電腦具備量子疊加態與量子干涉特性。秀爾演算法構造量子週期態後，利用量子傅立葉轉換（QFT, Quantum Fourier Transform）能在多項式時間 O((log N)³) 內精準捕獲該週期，瞬間解出質因數 p, q！這意味著一旦實用容錯量子電腦誕生，現存所有 RSA 與 ECC 體系將在一秒內徹底瓦解。
0.2 現代晶格密碼學的幾何範式轉移 (Lattice-based Paradigm Shift) 後量子破局

後量子晶格密碼學（Lattice-based Cryptography）與全同態加密（Fully Homomorphic Encryption, FHE）帶來了密碼學史上最徹底的範式轉移（Paradigm Shift）：

  • 【脫離一維循環週期，踏入千維幾何晶格】： 晶格加密不再依賴代數群的階與週期，而是將金鑰與密文映射到 n = 1024 維甚至更高維的歐幾里得空間離散幾何點陣（Euclidean Lattice）中。 高維晶格不存在阿貝爾群的隱子群週期性，格點在空間中隨機旋轉與傾斜，使得秀爾量子演算法完全失去抓手。
  • 【為什麼必須引入微小隨機雜訊 (Noise)？】： 設想若無雜訊，密文方程寫為：b = ⟨a, s⟩ + m (mod q)。 此時攻擊者收集 n 筆密文，即可列出 n 元一次線性方程組，直接使用國中程度的高斯消去法在毫秒內精確解出私鑰 s！ 為了阻斷線性代數消去破解，現代晶格密碼在方程中刻意注入微小離散高斯雜訊 e：
    b = ⟨a, s⟩ + e + m · ⌊q/t⌉ (mod q)
    這微小的雜訊 e 徹底打破了嚴格的線性等式，使得解方程退化為極其艱難的容錯學習問題（LWE, Learning With Errors）。在數學證明上，破解 LWE 等價於在千維幾何晶格中找出最短向量，哪怕最強大的量子電腦也只能耗費指數級時間 2Ω(n) 暴力搜尋！
  • 【全同態加密 (FHE) 的誕生契機】： 密文形式 (a, b) 具備非凡的代數加法與乘法同態特性：兩筆密文相加，明文自然相加；密文多項式卷積相乘，明文自然相乘！雲端伺服器在完全不知道明文與私鑰的前提下，可直接在密文上執行任意深度的機器學習模型或門檻 MPC 運算。

基礎知識閱讀 (一) — 數論與同餘模算術 (Modular Arithmetic)

同餘等價類、平衡餘數系、擴展歐幾里得乘法反元素 (EEA) 與殘數數系 (CRT/RNS) 深度解析與數值推導
1.1 模同餘基本概念與平衡餘數空間 (Congruence Modulo) 數論核心根基

在晶格密碼與同態加密中，所有整數運算均在特定的整數模數 q 下進行，防止數值無限增長並構成週期性離散空間。

  • 【模同餘嚴格定義】： 設 q ≥ 2 為正整數（稱為模數 Modulus）。若整數 a 與 b 除以 q 的餘數相同，即 q 能整除其差值 (a - b)，則稱 a 與 b 模 q 同餘，記為：
    a ≡ b (mod q) ⟺ q | (a - b) ⟺ a = k · q + b (k ∈ ℤ)
  • 【同餘運算保全性】： 若 a₁ ≡ b₁ (mod q) 且 a₂ ≡ b₂ (mod q)，則：
    • 加法同餘：(a₁ + a₂) ≡ (b₁ + b₂) (mod q)
    • 減法同餘：(a₁ - a₂) ≡ (b₁ - b₂) (mod q)
    • 乘法同餘：(a₁ · a₂) ≡ (b₁ · b₂) (mod q)
  • 【平衡餘數區間 (Centered Remainder Representation)】： 標準餘數空間為非負區間 [0, q - 1]。然而，密碼學中的誤差與雜訊具有正負對稱性（例如 +2 與 -2 代表大小相同但方向相反的雜訊）。 因此，理論與工程上更常採用以 0 為中心的平衡餘數區間：
    ℤq ≅ [ -⌊q/2⌋, ⌊(q - 1)/2⌋ ]
    數值換算範例：當 q = 17 時，標準區間數值 16 換算為平衡區間為 16 - 17 = -1，數值 15 換算為 -2，數值 14 換算為 -3。這使得微小的負向雜訊能夠直觀表達，避免被誤認為極大正數。
1.2 乘法反元素 (Modular Inverse) 與擴展歐幾里得演算法 (EEA) 除法替代方案

密碼學痛點：模運算中沒有小數與實數除法！ 在實數中計算 b / a 可以直接除；但在整數模群 ℤq 中，除以 a 必須等價轉化為「乘以 a 的乘法反元素」。

  • 【定義】：若整數 x 滿足 a · x ≡ 1 (mod q)，則稱 x 為 a 在模 q 下的乘法反元素，記為 a⁻¹ (mod q)。
  • 【存在充要條件】：a⁻¹ (mod q) 存在的充分且必要條件為 gcd(a, q) = 1（即 a 與 q 互質）。若 q 為質數，則只要 a ≢ 0 (mod q)，其乘法反元素必然存在且唯一。
  • 【費馬小定理 (Fermat's Little Theorem)】：若 q 為質數，則對於任意不被 q 整除的整數 a，恆有 aq-1 ≡ 1 (mod q)。將兩邊同除以 a，即可得出：
    a⁻¹ ≡ aq-2 (mod q)
🔢 數值計算範例：擴展歐幾里得演算法 (EEA) 逐步求解乘法反元素
目標：計算 a = 7 在模數 q = 23 下的乘法反元素 7⁻¹ mod 23。

第一階段：正向輾轉相除求 gcd(23, 7)
• 式 (1)：23 = 3 · 7 + 2      (商數 3，餘數 2)
• 式 (2)：7 = 3 · 2 + 1       (商數 3，餘數 1，抵達互質基準！)
• 式 (3)：2 = 2 · 1 + 0       (餘數為 0，驗證 gcd(23, 7) = 1)

第二階段：逆向回代求 Bézout 恆等式 1 = 23 · x + 7 · y
• 由式 (2) 移項得：1 = 7 - 3 · 2
• 由式 (1) 將餘數 2 = 23 - 3 · 7 代入上式消去 2：
  1 = 7 - 3 · (23 - 3 · 7)
  1 = 7 - 3 · 23 + 9 · 7
  1 = 10 · 7 - 3 · 23

第三階段：兩端取模 23 求出反元素
• 10 · 7 - 3 · 23 ≡ 10 · 7 - 0 ≡ 1 (mod 23)
• 結論：7⁻¹ ≡ 10 (mod 23)！
• 驗算：7 · 10 = 70 = 3 · 23 + 1 ≡ 1 (mod 23)，結果完全正確！
1.3 中國剩餘定理 (CRT) 與殘數數系 (RNS, Residue Number System) 超大模數平行化

在全同態加密（Leveled BGV / BFV / CKKS）中，為了容納多層連續乘法累積的龐大雜訊，密文模數 Q 必須達到數百至上千位元。 通用 CPU 的 64 位元暫存器無法直接處理千位元大數乘法。殘數數系（RNS）結合中國剩餘定理（CRT）是現代同態密碼庫（如 Microsoft SEAL、OpenFHE）達到即時運算的基石。

  • 【CRT 同構定理】：設 q₀, q₁, …, qk-1 為兩兩互質的小質數（通常為 50~60 位元的機器字長質數），合成大模數為 Q = ∏i=0k-1 qi。則大整數環 ℤQ 與各小質數分量的直積環存在唯一的環同構映射：
    ℤQ ≅ ℤq₀ × ℤq₁ × ⋯ × ℤqk-1
    任意千位元大數 X ∈ ℤQ 可精確分解為餘數短向量 (x₀, x₁, …, xk-1)，其中 xi = X mod qi。
  • 【RNS 巨大加速優勢】： 加法與乘法可直接在各個 qi 通道中完全平行獨立計算，通道間零進位、零依賴！CPU 或 GPU 可使用 AVX-512 SIMD 指令同時對 8 個質數通道執行單週期乘法。
🔢 數值計算範例：CRT 殘數合成重建完整大數
設三個互質小質數為 q₀ = 3, q₁ = 5, q₂ = 7，合成大模數 Q = 3 · 5 · 7 = 105。
已知某大數在三個通道中的餘數分別為：x ≡ 2 (mod 3)、x ≡ 3 (mod 5)、x ≡ 2 (mod 7)。

第一步：計算各通道局部除數 Mi = Q / qi
• M₀ = 105 / 3 = 35
• M₁ = 105 / 5 = 21
• M₂ = 105 / 7 = 15

第二步：計算局部乘法反元素 yi = Mi⁻¹ mod qi
• y₀ = 35⁻¹ mod 3 ≡ 2⁻¹ mod 3 ≡ 2 (因為 2 · 2 = 4 ≡ 1 mod 3)
• y₁ = 21⁻¹ mod 5 ≡ 1⁻¹ mod 5 ≡ 1 (因為 1 · 1 ≡ 1 mod 5)
• y₂ = 15⁻¹ mod 7 ≡ 1⁻¹ mod 7 ≡ 1 (因為 1 · 1 ≡ 1 mod 7)

第三步：代入 CRT 重建公式加權求和
• x = ( ∑i=0² xi · Mi · yi ) mod Q
• x = (2 · 35 · 2 + 3 · 21 · 1 + 2 · 15 · 1) mod 105
• x = (140 + 63 + 30) mod 105 = 233 mod 105 = 23！
• 驗算：23 mod 3 = 2，23 mod 5 = 3，23 mod 7 = 2，三通道完全精確吻合！

基礎知識閱讀 (二) — 抽象代數基石 (Abstract Algebra)

群/環/體層級結構、旋輪商環多項式 R_q 負循環摺積、NTT 加速與有限體代數性質
2.1 代數結構層次階梯：群 (Group) ⟶ 環 (Ring) ⟶ 體 (Field) 代數體系全覽

現代密碼學建立在嚴謹的代數結構之上。理解「群、環、體」的差異與能力邊界，是讀懂多項式商環與門檻秘密分享的前提。

  • 【群 (Group, G)】： 包含一個二元運算（通常記為加法 +），滿足四條基本公理：
    ① 封閉性：任意 a, b ∈ G 則 a + b ∈ G。
    ② 結合律：(a + b) + c = a + (b + c)。
    ③ 單位元：存在 0 ∈ G 使得 a + 0 = a。
    ④ 反元素：對任意 a ∈ G 存在 -a ∈ G 使得 a + (-a) = 0。
    若加法還滿足交換律（a + b = b + a），則稱為阿貝爾群（Abelian Group）。整數加法模群 (ℤq, +) 即為典型阿貝爾群。
  • 【環 (Ring, R)】： 具備加法與乘法兩種運算。 在加法下為阿貝爾群；在乘法下滿足結合律與對加法的分配律。
    關鍵痛點：環中的元素不一定存在乘法反元素！ 例如整數環 ℤ 中，只有 1 與 -1 存在乘法反元素；多項式環 ℤ[X] 中，次數大於等於 1 的多項式皆無法求乘法反元素（除法無法整除）。
  • 【體 (Field, F)】： 若環中所有的非零元素在乘法下也構成阿貝爾群（即每個非零元素皆存在唯一的乘法反元素），則稱為「體」。 實數體 ℝ、有理數體 ℚ 以及當模數 p 為質數時的整數有限體 𝔽p（又稱伽羅瓦體 GF(p)）皆為體。在體中可以自由進行加、減、乘、除四則運算。
2.2 旋輪多項式商環 ℛq = ℤq[X]/(XN+1) 的代數與幾何本質 FHE 核心引擎

為什麼全同態加密（Ring-LWE, BFV, BGV, CKKS, TFHE）全部建立在多項式商環 ℛq 之上？

  • 【普通多項式相乘的維度爆炸痛點】： 若在一般多項式環 ℤq[X] 中運算，兩個 N - 1 次的多項式相乘後，次數會膨脹為 2N - 2 次。 連續進行 10 次同態乘法，多項式長度將暴增千倍，密文體積與計算複雜度將發生指數級災難！
  • 【模 XN + 1 負循環折疊機制 (Negacyclic Convolution)】： 選用第 2N 次分圓多項式 Φ2N(X) = XN + 1 作為理想模除基底，代數上強制約定：
    XN + 1 ≡ 0 ⟹ XN ≡ -1 ⟹ XN+k ≡ -Xk
    這意味著：任何次數達到或超過 N 的高次項，只要遇到 XN 就自動反號折回（Wrap around with negative sign）變成低次項！多項式長度被永久強制鎖定在 N 個係數以內。
  • 【數論轉換 (NTT) 加速至 O(N log N)】： 當環維度 N 為 2 的冪次方且模數滿足 q ≡ 1 (mod 2N) 時，商環上的負循環摺積可透過數論轉換（NTT, 類似離散傅立葉轉換 FFT）在 O(N log N) 時間內極速完成，比傳統卷積 O(N²) 快數千倍！
🔢 數值計算範例：商環多項式乘法與負循環折疊逐步推導
設多項式度數 N = 4，係數模數 q = 13，商環為 ℛ₁₃ = ℤ₁₃[X]/(X⁴ + 1)。
給定兩多項式：a(X) = 2X³ + 4X，b(X) = 3X² + 5。

第一步：普通多項式展開相乘
• a(X) · b(X) = (2X³ + 4X)(3X² + 5)
• = 2X³ · 3X² + 2X³ · 5 + 4X · 3X² + 4X · 5

基礎知識閱讀 (六) — 計算複雜度與可證明安全基石 (Provable Security)

6.1 漸近複雜度與多項式時間 (Asymptotic Complexity & Polynomial Time) 計算開銷基石
  • 【安全參數 λ (Security Parameter)】： 衡量密碼系統抵抗攻擊強度的核心標尺。現代後量子標準通常要求 λ = 128 位元安全（即攻擊者成功破譯所需的運算步驟必須不低於 2¹²⁸ 次運算）。
  • 【多項式時間 poly(λ) 的效率底線】： 合法參與者的操作（加密、解密、同態評估、門檻金鑰分發）的計算複雜度與通訊量，必須是安全參數的多項式函數（如 O(λ²), O(λ³)），確保系統在實務硬體上秒級運行。
  • 【指數級攻擊屏障 2Ω(λ)】： 敵手破解密文、偽造簽章或提取私鑰的任何演算法開銷，必須隨安全參數呈指數級增長（2Ω(λ)）。在 λ = 128 下，即使用全球所有超級電腦並行計算至宇宙毀滅，也無法完成破譯。
6.2 可忽略函數 (Negligible Function negl(λ)) 的嚴密數學定義 機率極限定義

在密碼學中，我們不能簡單地要求作弊機率為「0」（因為敵手隨機猜測也有微小機率猜中）。我們要求作弊機率必須是「可忽略的（Negligible）」。

  • 【嚴格數學定義】： 若函數 f: ℕ → ℝ 滿足：對於任意給定的正多項式 p(λ)，皆存在常數 λ₀ 使得對於所有 λ > λ₀，恆有：
    f(λ) < 1 / p(λ)
    則稱 f(λ) 為可忽略函數，通常記為 negl(λ)。
  • 【直觀理解】： 可忽略函數衰減的速度比任何多項式的倒數都要快得多！典型代表為 2-λ 或 λ-log λ。 在密碼學證明中，若攻擊者猜中私鑰、偽造 ZKP 證明的機率滿足 Pr[Attack] ≤ negl(λ)，則該系統在數學上即被認定為「絕對不可破譯」。
6.3 遊戲式安全模型 (Game-based Security) 與敵手優勢 (Advantage) 可證明安全範式
  • 【博弈框架 (Cryptographic Game)】： 密碼學安全性透過「挑戰者（Challenger）」與多項式時間「敵手（Adversary 𝒜）」之間的嚴格博弈遊戲來定義。 例如在選擇明文不可區分性（IND-CPA）遊戲中，敵手提交兩條等長明文 m₀, m₁，挑戰者擲硬幣 b ∈ {0, 1} 並將 c* = Enc(mb) 回傳給敵手，敵手輸出猜測 b'。
  • 【敵手優勢 (Advantage) 定義】： 敵手猜對 b' = b 的機率相較於純盲猜（機率 1/2）的超額差距：
    Adv𝒜(λ) = | 2 · Pr[b' = b] - 1 | = | Pr[b' = 1 | b = 1] - Pr[b' = 1 | b = 0] |
  • 【安全判定準則】： 若對於任何多項式時間敵手 𝒜，其優勢皆嚴格滿足 Adv𝒜(λ) ≤ negl(λ)，則證明該加密體系滿足 IND-CPA 安全等級！
6.4 隨機預言機模型 (ROM) 與 Fiat-Shamir 啟發式轉換 主動安全引擎
  • 【隨機預言機模型 (Random Oracle Model, ROM)】： 一種密碼學證明假設，假設存在一個全域公共的理想隨機黑盒。對任何輸入字串 x，黑盒均即時產生並回傳一個均勻分佈的隨機輸出 H(x)，且對相同輸入永遠給出相同輸出。在實務工程中，隨機預言機通常由 SHA-3、SHAKE-256 或 BLAKE3 等強密碼學雜湊函數實體化。
  • 【Fiat-Shamir 啟發式轉換 (三輪交互 ⟶ 單輪 NIZK)】： 在傳統零知識證明（如 Schnorr 協議）中，證明者與驗證者需要三輪握手（證明者發送承諾 a ⟶ 驗證者隨機挑戰 c ⟶ 證明者發送回應 z）。在廣域分散式網路中，這將帶來嚴重的通訊輪數延遲。 藉由 Fiat-Shamir 轉換，證明者將驗證者的隨機挑戰替換為向隨機預言機查詢公開陳述與承諾的雜湊值：
    c = H( 公開陳述 || 承諾值 a )
    這直接將多輪交互式協議壓縮為單輪非交互式零知識證明（NIZK）！證明隨密文份額一同廣播，任何節點均可單機自主驗證，構成了現代區塊鏈與門檻同態加密抵抗主動惡意作弊的核心防線！

背景知識 (一) — LWE 晶格加密基礎、幾何數學難題與矩陣運算範例

1.1 幾何晶格基礎理論 (Lattice Geometry & Foundations) 幾何空間根基

在傳統數論密碼學（如 RSA、ECC）面臨量子 Shor 演算法多項式時間破解威脅的背景下，現代後量子與全同態密碼學全面建立於高維歐幾里得幾何晶格（Euclidean Lattice）之上。

  • 【工具定義：幾何晶格 (Lattice)】： 設 B = {b₁, b₂, …, bn} ⊂ ℝm 為一組由 n 個線性獨立的 m 維向量所組成的矩陣（稱為晶格的「基底」，m ≥ n）。由該基底生成的幾何晶格 Λ(B) 定義為全體整數線性組合構成的離散點陣空間：
    Λ(B) = { ∑i=1n xi · bi | xi ∈ ℤ } = { B · x | x ∈ ℤn }
    其中維度 n 稱為晶格的秩（Rank），當 m = n 時稱為滿秩晶格（Full-rank Lattice）。
  • 【基本並行多面體與晶格行列式】： 任一基底 B 圍成的半開半閉多胞體稱為基本並行多面體（Fundamental Parallelepiped）：
    𝒫(B) = { ∑i=1n ti · bi | 0 ≤ ti < 1, ti ∈ ℝ }
    該多胞體的體積在代數上等於基底矩陣的行列式絕對值，記為晶格行列式 det(Λ) = √det(BT · B)。 雖然同一晶格存在無窮多組不同的基底，但晶格行列式 det(Λ) 是晶格內在的不變量，幾何上反映了晶格點在空間中的全域平均分佈密度（點密度為 1 / det(Λ)）。
  • 【連續空間中的第一連續極小值 (Successive Minima)】： 幾何上定義第 i 個連續極小值 λi(Λ) 為能夠包含 i 個線性獨立晶格點的最小封閉超球半徑。特別地，λ₁(Λ) 代表晶格中最短非零晶格向量的長度：
    λ₁(Λ) = minv ∈ Λ, v ≠ 0 ‖v‖
    根據 Minkowski 第一凸體定理，在滿秩晶格中，最短向量長度受到晶格行列式嚴格約束：λ₁(Λ) ≤ √n · (det(Λ))1/n。
  • 【對偶晶格 (Dual Lattice)】： 定義為與原始晶格點乘積恆為整數的所有向量集合：Λ* = { y ∈ span(Λ) | ∀ x ∈ Λ, ⟨x, y⟩ ∈ ℤ }。其生成基底為 D = B · (BT · B)−1，滿足體積倒數關係 det(Λ*) = 1 / det(Λ)，是證明晶格問題困難度歸約的重要工具。
1.2 晶格底層三大經典幾何數學難題 (SVP, SIVP & CVP) 後量子硬度根基

後量子密碼之所以能抵禦量子計算攻擊，核心在於底層幾何晶格難題在已知最高階演算法（包含 Shor 演算法在內）下均不具備多項式時間解法。三大核心難題定義如下：

  • 【難題一：最短向量難題 (SVP, Shortest Vector Problem)】：
    • 【定義】：給定某晶格的一組任意隨機基底 B，在晶格中尋找一個非零晶格向量 v ∈ Λ (v ≠ 0)，使得其歐幾里得範數達到全域最小：
    ‖v‖ = λ₁(Λ) = minx ∈ Λ, x ≠ 0 ‖x‖

    • 【近似版本 γ-SVP】：給定近似因子 γ ≥ 1，尋找非零向量 v ∈ Λ (v ≠ 0) 使得 ‖v‖ ≤ γ · λ₁(Λ)。
    • 【計算複雜度】：精確 SVP 為 NP-hard（在隨機歸約下）；當近似因子 γ = poly(n)（多項式級）時，目前最佳演算法（BKZ 演算法）仍需要指數級時間 2Ω(n)。
  • 【難題二：最短獨立向量難題 (SIVP, Shortest Independent Vectors Problem)】：
    • 【定義】：給定滿秩晶格基底 B ∈ ℤn×n 與近似因子 γ ≥ 1，尋找 n 個線性獨立的晶格向量 {v₁, v₂, …, vn} ⊂ Λ，滿足：
    max1 ≤ i ≤ n ‖vi‖ ≤ γ · λn(Λ)
    該問題要求找到覆蓋晶格全部維度的短向量基底組，是平均情況與最差情況歸約理論的關鍵樞紐。
  • 【難題三：最近向量難題 (CVP, Closest Vector Problem) 與 BDD】：
    • 【定義】：給定晶格基底 B 與空間中任意目標向量 t ∈ ℝm，在晶格中尋找距離目標最近的晶格點 v ∈ Λ，使得 ‖t − v‖ = dist(t, Λ) = minx ∈ Λ ‖t − x‖。
    • 【有界距離解碼 (BDD, Bounded Distance Decoding)】：若保證目標點 t 距離晶格點的距離嚴格小於 α · λ₁(Λ)（其中 α < 1/2），尋找唯一的最近晶格點。LWE 解密本質上就是 BDD 難題的例項！
  • 【決策型晶格難題 (GapSVPγ)】： 給定晶格基底 B 與標稱半徑 d，判定該晶格的最短向量究竟滿足 λ₁(Λ) ≤ d 抑或 λ₁(Λ) > γ · d。兩者之間留有 γ 倍隙縫，是密碼學證明中最標準的底層困難假設。
1.3 LWE 困難假設與 Regev 最差至平均量子歸約定理 密碼學核心定理

現代同態加密不直接基於幾何晶格構造，而是基於 Oded Regev 於 2005 年提出的容錯學習問題（LWE, Learning With Errors）。Regev 從數學上建立了隨機 LWE 實例與幾何晶格最差情況難題之間的嚴密等價橋樑。

  • 【搜尋型 LWE (Search-LWE)】： 設私鑰為均勻隨機向量 s ∈ ℤqn。給定任意多組採樣樣本 (ai, bi = ⟨ai, s⟩ + ei mod q)，其中基底向量 ai ∈ ℤqn 均勻隨機採樣，誤差 ei ← χ 採樣自標準差為 σ = α · q 的離散高斯分佈。目標為從有限組樣本中恢復出真實私鑰向量 s。
  • 【決策型 LWE (Decision-LWE)】： 區分兩類分佈的難題：一類是真實 LWE 樣本 (a, ⟨a, s⟩ + e mod q)，另一類是完全在 ℤqn × ℤq 均勻隨機採樣的噪聲對。在計算複雜度上，Decision-LWE 與 Search-LWE 具備多項式時間可互相歸約性。
  • 【Regev 最差情況至平均情況量子歸約定理 (Worst-Case to Average-Case Quantum Reduction)】：
    • 【定理核心】：Regev 證明了：「如果存在任何多項式時間演算法能以不可忽略的優勢攻破平均情況（Average-Case）下的 LWE 實例，則必存在一個高效率量子演算法，能在最差情況（Worst-Case）下求解任意 n 維幾何晶格上的 GapSVPγ 與 SIVPγ 難題（其中近似因子 γ = Õ(n / α)）！」
    • 【密碼學重大意義】：傳統 RSA/ECC 要求金鑰生成必須避開「特殊弱金鑰」；而在 LWE 體系中，即使隨機產生私鑰，其安全性也能等價於幾何空間中最硬的晶格實例！
1.4 LWE / RLWE / MLWE / RNS-GLWE 晶格加密全景 代數維度演進

為提升全同態加密的計算效率並支援多資料打包（SIMD），密碼學界將純量整數向量逐步推廣至多項式環代數結構：

  • 【標準純量 LWE】： 定義於整數有限域向量空間 ℤqn。
    • 優勢：數學結構最純粹，不存在環上的代數弱結構，是 TFHE 盲旋轉自舉與基礎門檻解密的核心單位。
    • 劣勢：密鑰與密文尺寸龐大，計算為矩陣乘法，無法利用多項式卷積加速。
  • 【環容錯學習 (Ring-LWE, RLWE)】： 定義於分圓多項式環 Rq = ℤq[X] / (XN + 1)（維度 N 為 2 的冪次）。
    • 代數特徵：私鑰與密文分量均為多項式 s(X), a(X), b(X) ∈ Rq。
    • NTT 卷積加速：若模數滿足 q ≡ 1 mod 2N，可透過數論變換（NTT）將多項式乘法複雜度由 O(N²) 驟降至 O(N log N)，實現千倍級效能躍升。
    • SIMD 槽打包：利用分圓環的素理想分解定理，單個 RLWE 密文可同時打包 N 個明文槽（Slots），實現資料並行同態計算。
  • 【模組化容錯學習 (Module-LWE, MLWE)】： 定義於多項式環向量空間 Rqk（維度為 k × N）。
    • 折衷優勢：兼具 RLWE 的多項式快速卷積，又克服了 RLWE 環維度 N 只能以 2 的冪次跳躍（1024, 2048, 4096…）的缺陷，可藉由微調向量維度 k 平滑調整安全位元。
  • 【餘數數系多階通用晶格 (RNS-GLWE)】： 針對大位元模數 Q（如 100~800 bits），利用中國剩餘定理（CRT）將模數分解為多個 60 位元機器字長的小 NTT 素數乘積 Q = ∏i=1L qi。
    • 硬體原生加速：全域運算無需大數高精度庫，全部在 CPU/GPU 暫存器中以 64 位元硬體指令並行運算。
1.5 矩陣向量完整範例：LWE 矩陣與向量加解密步進數值演練 實體矩陣向量運算

本節以具體的 4×3 維度整數矩陣 與 3 維列向量 為例，完整展示從金鑰生成、公鑰加密到解密相位計算與四捨五入還原的每一步代數演算。

  • 【工具定義：矩陣形式 LWE (Matrix-Form Public Key LWE)】：
    • 設晶格私鑰為長度為 n 的未知向量 s ∈ ℤqn。
    • 公開隨機矩陣 A ∈ ℤqm×n（代表 m 組隨機基底測試向量）。
    • 誤差高斯雜訊向量 e ∈ ℤqm。
    • 公鑰向量計算為矩陣乘以向量加上雜訊：b = A · s + e mod q ∈ ℤqm。全體公鑰為數對 (A, b)。
  • 【加密運算流程 (Encryption via Random Transpose Matrix)】：
    • 設欲加密之明文數值為 μ ∈ ℤt，縮放步距為 Δ = ⌊q / t⌉。
    • 採樣隨機稀疏臨時短向量 r ∈ {0, 1}m 與加密微小雜訊 eenc ∈ ℤ。
    • 密文向量第一分量：u = AT · r mod q ∈ ℤqn。
    • 密文標量第二分量：v = bT · r + Δ · μ + eenc mod q ∈ ℤq。
    • 輸出密文為數對：c = (u, v) ∈ ℤqn × ℤq。

2.1 同態加法與乘法：代數結構與雜訊幾何相乘展開 運算幾何本質

同態加密（Homomorphic Encryption）允許直接對密文進行代數運算，其解密結果精確等同於明文運算結果。然而，密文運算的同時伴隨著雜訊（Noise）的持續增長：

  • 【同態加法 (Homomorphic Addition)】：
    • 【工具定義】：設兩密文 c₁ = (a₁, b₁) 與 c₂ = (a₂, b₂)，同態加法直接定義為向量分量之整數和：
    cadd = c₁ + c₂ = (a₁ + a₂ mod q, b₁ + b₂ mod q)

    • 【運作過程與相位疊加】：計算解密相位：
    phaseadd = (b₁ + b₂) − ⟨a₁ + a₂, s⟩ = (b₁ − ⟨a₁, s⟩) + (b₂ − ⟨a₂, s⟩) = Δ · (m₁ + m₂) + (e₁ + e₂) mod q

    • 【優點與缺點】：新雜訊滿足絕對值三角不等式 |eadd| ≤ |e₁| + |e₂|，呈線性溫和累加；開銷極微，可連續執行數千次加法。
  • 【同態乘法 (Homomorphic Multiplication & Tensor Product)】：
    • 【工具定義】：兩密文之相位乘積展開對應兩密文向量的外積（張量積 c₁ ⊗ c₂）。
    • 【運作過程與雜訊交乘展開】：
    phase₁ · phase₂ = [Δ · m₁ + e₁] · [Δ · m₂ + e₂] = Δ² · (m₁ · m₂) + Δ · (m₁e₂ + m₂e₁) + e₁e₂
    為了將明文空間係數自 Δ² 重新除以 Δ 歸一化回標準步距 Δ，密文必須除以 Δ：
    (1 / Δ) · phase₁ · phase₂ = Δ · (m₁ · m₂) + (m₁e₂ + m₂e₁) + ⌊ e₁e₂ / Δ ⌉

    • 【優點與缺點】：雖然實現了圖靈完備的算術電路，但交乘項 (m₁e₂ + m₂e₁) 導致雜訊呈指數級幾何爆炸；且解密多項式變為私鑰變數的二次型多項式，密文長度由 (n+1) 膨脹至 O(n²)！
🔢 具體算式範例：同態加法 vs. 同態乘法雜訊膨脹對比

設模數 q = 1000，明文模數 t = 10，縮放步距 Δ = 100，容許雜訊上限為 Δ / 2 = 50。
• 密文 1：明文 m₁ = 2，初始雜訊 e₁ = 3 ⟹ phase₁ = 100·2 + 3 = 203。
• 密文 2：明文 m₂ = 3，初始雜訊 e₂ = 4 ⟹ phase₂ = 100·3 + 4 = 304。
① 同態加法：phaseadd = 203 + 304 = 507 = 100·(2+3) + (3+4)。新雜訊為 7，僅佔上限 50 的 14%，依然非常乾淨！
② 同態乘法：交乘展開式 203 · 304 = 61712。除以 Δ = 100 並四捨五入得 617 = 100·(2·3) + 17。
單次乘法後的新雜訊劇增至 17（增長率高達 400%）！若再執行一次乘法，雜訊將破百直接超出容許上限 50，導致解密徹底雪崩損毀！

2.2 密文重線性化技術 (Relinearization & Evaluation Keys, RLK) 維度降階關鍵

同態相乘後產生的二次密文張量包含交叉項 si · sj，若不予降維，多次乘法將使密文維度隨乘法深度成指數級膨脹（O(nL)）。重線性化（Relinearization）利用公開評估金鑰（RLK）將二次密文無損投射回原始一次維度。

  • 【工具定義：重線性化金鑰 (Evaluation Key / RLK)】： 公鑰生成端預先對私鑰張量外積 s ⊗ s 進行加密，產出針對二次項的特殊公鑰集合：
    RLKk = ( ak, bk = ak · s + ek + Bk · s² mod q )
    其中 B 為數位基底分解基數（Gadget Matrix Base），用以防止金鑰替換時乘數過大導致雜訊被放大。
  • 【運作過程：六步降階全流程】：
    • 步驟 ① 生成二次密文：兩密文乘積展開為三元組 (c₀, c₁, c₂)，其解密關係滿足 c₀ − c₁·s − c₂·s² ≈ Δ·m mod q。
    • 步驟 ② 數位基底切片 (Digit Slicing)：將大係數 c₂ 依基底 B 切分為微小整數向量：c₂ = ∑ dk · Bk（其中 |dk| < B）。
    • 步驟 ③ 評估金鑰內積：利用各權重階層的 RLKk = (ak, bk) 與切片係數 dk 進行加權線性組合：
    Δa = ∑ dk · ak mod q, Δb = ∑ dk · bk mod q

    • 步驟 ④ 維度折疊 (Folding)：將高階分量折疊回一次密文：
    c₀' = c₀ − Δb mod q, c₁' = c₁ − Δa mod q

    • 步驟 ⑤ 一次解密驗證：持一次私鑰計算 c₀' − c₁'·s mod q = Δ·m + enew，成功由三元組降維回標準二元組！
  • 【優點與缺點】：
    • 優點：將密文維度恆定約束在 n + 1，使得任意深度的乘法電路在空間複雜度上具備可行性。
    • 缺點：RLK 金鑰尺寸龐大（需儲存多階金鑰），且會引入小幅度的基底分解雜訊 B · √d · σ。

【第一步：選定參數與初始二次密文】
設模數 q = 97，縮放步距 Δ = 49，私鑰標量 s = 5（其平方為 s² = 5² = 25）。

化簡模 97：−292 + 3·97 = −292 + 291 = −1 ≡ 96 mod 97。

2.3 雜訊控制機制一：TFHE / FHEW 盲旋轉自舉 (Blind Rotation Bootstrapping) 無限深度保證

當同態乘法累積的雜訊逼近上限時，若無外部干預，下一次運算必將損壞明文。自舉（Bootstrapping）是 Craig Gentry 提出的全同態破局機制：在密文域內同態執行解密電路自身，輸出一個明文完全不變、但雜訊被重置為全新小常數雜訊的嶄新密文。現代實踐以 TFHE 盲旋轉最為卓越。

  • 【工具定義：TFHE 盲旋轉 (Blind Rotation)】： 將 LWE 密文相位 phase = b − ⟨a, s⟩ 作為環多項式單項式 X−phase 的幾何旋轉角度，利用 GSW / RGSW 外積乘法同態旋轉環累加器多項式（Accumulator Poly），在密文內部盲查表（Programmable Bootstrapping, PBS）。
  • 【運作過程：五步自舉流水線】：
    • 步驟 ① 檢測高雜訊密文：輸入密文累積雜訊接近臨界邊界，隨時面臨解密溢位風險。
    • 步驟 ② 模數切換降維至 2N：將密文從大模數 q 等比例縮放至分圓環維度 2N：ã = ⌊(2N/q)·a⌉, b̃ = ⌊(2N/q)·b⌉。
    • 步驟 ③ 裝載查表測試多項式 (LUT)：在反對稱多項式環 RQ = ℤQ[X]/(XN + 1) 構造累加器，將明文函數關係預先編碼進係數陣列。
    • 步驟 ④ 步進式盲旋轉求值 (CMux & BSK)：累加器先旋轉公開項 X−b̃，再以自舉金鑰 BSK 控制依次乘上私鑰項 Xãi·si，最終整體旋轉角度恰好等於 X−phase！
    • 步驟 ⑤ 常數項提取 (Sample Extract)：提取旋轉後多項式的常數項係數，舊密文累積的所有歷史雜訊在查表中被徹底擦除，重置為全新常數雜訊！
  • 【優點與缺點】：
    • 優點：支援無限深度（True FHE），單次自舉延遲在數十毫秒以內，可任意求值各類非線性活化函數（ReLU、Sigmoid、階躍函數）。
    • 缺點：單個密文通常僅打包 1 個或少數幾個位元（Boolean/Integer），不擅長數千資料槽的大規模 SIMD 並行吞吐。

• ã = ⌊ 0.008 · 350 ⌉ = ⌊ 2.8 ⌉ = 3 ∈ ℤ₈
• b̃ = ⌊ 0.008 · 860 ⌉ = ⌊ 6.88 ⌉ = 7 ∈ ℤ₈

cfresh = Coeff₀(ACC₁) = −250 ≡ +250 mod 500。

2.4 雜訊控制機制二：RNS-NTT 批次模數鏈與模數切換 (Leveled FHE) 超高吞吐批次流

在大型巨量資料庫檢索與高維向量同態推論中，自舉的逐點開銷過於高昂。階梯式分層同態加密（Leveled FHE，如 BGV、BFV、CKKS）採用完全不同的哲學：不執行自舉，而是透過階梯式模數鏈（Modulus Switching Chain）在同態乘法後主動除以質數模數，強行壓制雜訊！

  • 【工具定義：階梯式 RNS 模數鏈 (Modulus Chain)】： 系統初始化時預先設定一個超大模數，由 L + 1 個 60 位元質數乘積構成：
    QL = ∏i=0L qi ⟹ QL-1 = ∏i=0L-1 qi ⟹ … ⟹ Q₀ = q₀
    密文初始位於最高層級 QL。
  • 【運作過程：五步模數切換縮放流水線】：
    • 步驟 ① 初始雙層模數鏈：設定頂層乘法模數 Q₁ = q₀ · q₁ 與底層模數 Q₀ = q₀。
    • 步驟 ② 頂層同態相乘：兩密文在 Q₁ 下相乘，交乘項導致雜訊隨乘積擴大至 e · q₁。

2.1 門檻秘密分享的核心理念與幾何分割 (Philosophy of Secret Sharing) 金鑰分散本質

在傳統集中式密碼系統中，私鑰 s 由單一伺服器持有，面臨單點入侵、權限濫用或實體硬碟毀損的不可逆風險。 門檻秘密分享技術將原始秘密 s 拆解為 N 份彼此獨立的「秘密份額（Shares）」s₁, s₂, …, sN，發放給各參與節點。唯有達到門檻數量的節點協同合作方能還原秘密或完成解密，任何低於門檻數量的勾結均在數學上完全無法獲得秘密的任何資訊。

2.2 工具一：全門檻加法秘密分享 (Additive Secret Sharing / N-of-N) 全門檻與不誠實多數
  • 【工具定義】： 在整數環 ℤQ 上，秘密 s 被拆分為 N 個份額，滿足代數和關係：
    s = ∑i=1N si (mod Q)
  • 【運作過程】：
    ① 份額分發：前 N−1 個節點的份額隨機均勻獨立採樣 si ← ℤQ；第 N 個節點的份額計算為：
    sN = s − ∑i=1N−1 si (mod Q)

    ② 協同部分解密：各節點使用手上的本地份額 si 計算部分解密值 pi = ⟨a, si⟩ mod Q。
    ③ 聚合重構：聚合器將所有收到的部分解密值直接相加：
    P = ∑i=1N pi = ∑i=1N ⟨a, si⟩ = ⟨a, ∑i=1N si⟩ = ⟨a, s⟩ (mod Q)
  • 【優點與缺點】：
    • 優點：達成不誠實多數（Anytrust / N−1 容錯），即使 N−1 人全部勾結，其視圖在資訊理論上依然與均勻隨機不可區分；且重構僅需純加法，通訊開銷為 0。
    • 缺點：零容錯性（0-Fault Tolerance）。任一節點離線或惡意發布錯誤數值，解密即告中斷。
🔢 具體算式範例：3-of-3 加法分享與完美隱匿證明

設模數 Q = 100，秘密 s = 42，節點數 N = 3。
1. 隨機採樣份額：s₁ = 73, s₂ = 85。
2. 計算最後一份額：s₃ = 42 − (73 + 85) = 42 − 158 = −116 ≡ 84 (mod 100)。
3. 驗算求和：s₁ + s₂ + s₃ = 73 + 85 + 84 = 242 ≡ 42 (mod 100)。
敵手勾結分析：假設節點 1 與節點 2 串通，他們持有的份額和為 73 + 85 = 58。 對於任何未知的候選秘密 s' ∈ {0, 1, …, 99}，都唯一存在一個合法的 s'₃ = s' − 58 mod 100。因為誠實節點 3 的份額是全域均勻抽樣的，敵手猜測任何一個秘密的機率完全均等為 1/100，獲得的資訊增益精確為 0。

2.3 工具二：有限體 Shamir 門檻秘密分享與本地 Lagrange 轉換 (T-of-N Shamir Sharing) 容錯門檻與多項式插值
  • 【工具定義】： 在質數有限體 ℤq 上，構造一個次數為 T−1 的隨機多項式，其常數項被鎖定為真實秘密 f(0) = s：
    f(X) = s + a₁ · X + a₂ · X² + … + aT−1 · XT−1 (mod q)
    其中係數 a₁, …, aT−1 ← ℤq 均勻獨立抽樣。
  • 【運作過程：Lagrange 插值與本地乘算轉換】：
    ① 份額發放：第 i 位參與者獲得多項式在非零點 X = i 處的點值 si = f(i) mod q。
    ② Lagrange 插值定理：任意選取在線的 T 位節點集合 S ⊆ {1, 2, …, N}，常數項可精確還原：
    s = f(0) = ∑i∈S λi,S · si (mod q), 其中 λi,S = ∏j∈S, j≠i (−j) · (i − j)−1 (mod q)

    ③ 本地免通訊轉換：由於 Lagrange 係數 λi,S 僅依賴於公開的在線成員編號集合 S，在線節點 i 可在本地預先將私鑰份額轉換為 s'i = λi,S · si mod q。 部分解密提交 p'i = ⟨a, s'i⟩ 後，聚合器依然只需執行純加法求和，通訊複雜度維持常數項 O(1)！
  • 【優點與缺點】：
    • 優點：靈活容錯，允許最多 N − T 個節點當機離線；少於 T 個節點勾結絕對無法獲得任何秘密。
    • 缺點：嚴格要求底層模數 q 必須為質數（保證 (i − j) 必然存在乘法反元素）。
🔢 具體算式範例：3-of-5 Shamir 分享在 ℤ₁₉ 上的精確重構演算法

在有限體 ℤ₁₉ 上，秘密 s = 7，門檻 T = 3。
隨機選取 2 次多項式：f(X) = 7 + 2X + 3X² (mod 19)。
份額點值為：s₁ = f(1) = 12，s₄ = f(4) = 63 ≡ 6，s₅ = f(5) = 92 ≡ 16 (mod 19)。
假設節點集合 S = {1, 4, 5} 進行重構：
計算節點 1 之插值係數：
λ₁ = [(0−4)·(0−5)] / [(1−4)·(1−5)] = 20 / [(−3)·(−4)] = 20 / 12 ≡ 1 / 12 = 12−1 (mod 19)。
由於 12 · 8 = 96 = 5·19 + 1 ≡ 1 (mod 19)，故 12−1 ≡ 8 ⟹ λ₁ = 8。
同理計算：λ₄ = 12，λ₅ = 0（在模 19 下各乘積計算）。
各方乘以份額求和：
s = 8 · 12 + 12 · 6 + 0 · 16 = 96 + 72 = 168 = 8 · 19 + 16 ≡ 7 (mod 19)！秘密 7 精準還原！

2.4 工具三：Galois 環 GR(2K, d) Shamir 分享與 Reed-Solomon 糾錯 (Error-Correcting Sharing) 非質數環與主動容錯
  • 【工具定義：Galois 環擴張 GR(2K, d)】： 在許多同態架構中，模數為 2 的冪次 2K（例如 2⁶⁴, 2¹²⁸）。在該環中，偶數皆為零因子，插值分母 (i − j) 若為偶數則無反元素，Shamir 插值直接崩潰。 為此構造多項式商環 GR(2K, d) = ℤ2K[X] / (F(X))，其中 F(X) 在模 2 商體 GF(2d) 上本原不可約。 在商體中選取非零互異元素作為評價點，保證在 Galois 環中差值必為可逆的單位元素（Unit）。
  • 【運作過程：Reed-Solomon 糾錯碼 (Robust Reconstruction)】：
    ① 各節點在 Galois 環中提交部分解密點值 (i, pi)。
    ② 當惡意節點提交竄改的假數值時，解密中心將收到的 N 個點值視為帶有雜訊的 Reed-Solomon 碼字。
    ③ 調用糾錯解碼演算法（如 Berlekamp-Massey 或 Welch-Berlekamp 演算法）。 只要惡意節點數量滿足 t < N / 3，演算法能自動定位出惡意節點的編號，並在代數上將錯誤數值修正，成功解碼出真實多項式常數項！
  • 【優點與缺點】：
    • 優點：相容 2 的冪次模數；在惡意攻擊下協議不中斷，達成保證輸出遞送（Guaranteed Output Delivery, GOD）。
    • 缺點：需要 Galois 環代數擴展，糾錯解碼演算法複雜度為 O(N · log² N)。

3.1 門檻解密的致命破口：為什麼雜訊洩漏等於私鑰洩漏？ (The Fatal Leakage Vulnerability) 核心破口分析

在門檻全同態系統中，各節點持有私鑰份額 si。 若採用天真的樸素門檻解密：各節點發布 pi = ⟨a, si⟩ (mod q)，聚合器相加得到 P = ⟨a, s⟩ 並計算 phase = b − P = Δ · m + e (mod q)，捨入得到明文 m。 這會立即暴露出最終密文的真實加密雜訊 e 的具體數值！

  • 【線性方程組攻擊原理 (Linear System Attack)】： 在同態運算中，密文雜訊是加乘電路的展開式。在無模數意義下，最終雜訊可展開為：
    e = ∑ kj · einit, j + ⟨α, s⟩
    其中係數向量 α 完全由公開的電路拓樸決定。 攻擊者只要發送 k 組測試密文請求解密，記錄每次洩漏的誤差值 e(1), e(2), …, e(k)，就能列出包含 n 個未知數的無模數線性方程組。利用高斯消去法在數微秒內即可完全解出私鑰向量 s！
🔢 具體算式範例：高斯消去法攻破無防護門檻解密

假設未知私鑰為 3 維向量 s = (s₁, s₂, s₃) = (2, −1, 3)。
攻擊者挑選 3 組已知明文為 0 的測試密文發起解密，側錄到殘餘雜訊：
• 查詢 1：送出 a(1) = (1, 2, 1) ⟹ 洩漏雜訊 e(1) = 1·(2) + 2·(−1) + 1·(3) = 3。
• 查詢 2：送出 a(2) = (2, 1, 0) ⟹ 洩漏雜訊 e(2) = 2·(2) + 1·(−1) + 0·(3) = 3。
• 查詢 3：送出 a(3) = (0, 3, 1) ⟹ 洩漏雜訊 e(3) = 0·(2) + 3·(−1) + 1·(3) = 0。
直接列出三元一次方程組：
① s₁ + 2·s₂ + s₃ = 3；② 2·s₁ + s₂ = 3；③ 3·s₂ + s₃ = 0。
由 ③ 得 s₃ = −3·s₂，代入 ① 得 s₁ − s₂ = 3，聯立 ② 解得：
s₁ = 2, s₂ = −1, s₃ = 3！僅需 3 次解密請求，整組私鑰無所遁形。

3.2 工具一：統計雜訊淹沒 (Noise Flooding / Smudging) 流派一：統計隱匿
  • 【工具定義】： 在各節點發布部分解密時，人為疊加一個巨額均勻隨機雜訊 Eflood ∈ [−Bflood, +Bflood]。 若原始雜訊上界為 B，設定 Bflood ≥ 2λ · B（λ 為統計安全參數，通常取 40 或 80）。
  • 【運作過程】：
    ① 各節點計算加噪部分解密：pi = ⟨a, si⟩ + Eflood, i mod q。
    ② 聚合器求和：phase = b − ∑ pi = Δ · m + e + ∑ Eflood, i mod q。
    ③ 根據 Smudging 引理，真實雜訊 e 與被淹沒後的總雜訊之間的統計距離滿足：
    SD(Eflood, e + Eflood) ≤ B / Bflood ≤ 2−λ
    在統計學上，敵手觀察到的殘存雜訊與純隨機均勻雜訊不可區分，私鑰相關項被徹底遮蔽。
  • 【優點與缺點】：
    • 優點：單輪非交互發布，實作極為簡約，安全證明直觀。
    • 缺點：密文模數 q 必須相應擴大 λ 個 bits（40~80 bits）以包容洪水雜訊，造成密文尺寸與多項式運算時間增加。
🔢 具體算式範例：Smudging 雜訊淹沒之模數擴展計算

設原始密文雜訊上界 B = 2¹⁰ = 1024，統計安全參數 λ = 40。
淹沒半徑：Bflood = 2⁴⁰ · 1024 = 2⁵⁰。
若明文空間 p = 4（佔 2 bits），為確保捨入不溢位（Bflood < Δ / 2 = q / (2·p) = q / 8），密文模數必須滿足：
q > 8 · Bflood = 2³ · 2⁵⁰ = 2⁵³。 原本單方加密只需 20 位元的計算，門檻統計淹沒要求模數至少提升至 53 位元。

3.3 工具二：無淹沒 MPC 協同捨入 (MPC Rounding via ℱABB) 流派二：閉門消噪
  • 【工具定義】： 完全不向外界公開部分解密！將部分解密計算與捨入函數完整封裝在通用安全多方計算（MPC）算術黑盒 ℱABB（如 SPDZ 協議）內部進行。
  • 【運作過程】：
    ① 各節點在黑盒內輸入私鑰份額，計算秘密分享狀態下的相位：[phase] = [b] − ⟨a, [s]⟩。

    低位的微小雜訊在秘密內部被精確截斷消除。
    ③ 各方僅廣播重構那個已經完全除盡、毫無雜訊殘留的明文 m。
  • 【優點與缺點】：
    • 優點：零模數膨脹（Zero Modulus Growth），直接採用現代處理器原生 32/64-bit 模數，並天然相容可調適通用可組合（UC）模擬安全。
    • 缺點：需要 3 次循序 Open（多輪通訊）與離線預處理三元組生成。
3.4 工具三：伺服器縮模與常數方差雜訊填充 (Server Rescaling & Noise Padding) 流派三：範數常數化
  • 【工具定義】： 引入輔助伺服器在解密前執行雙模數壓縮，並構造互補雜訊 ζ，使得解密後雜訊的總變異數永遠保持為與私鑰無關的公開常數 Bpub²。
  • 【運作過程】：
    ① 密文定義在雙模數 Q = p · q 上。輔助伺服器將密文縮壓至小模數 q，並注入對稱 PRF 掩碼。
    ② 傳統高斯雜訊方差依賴於私鑰長度 ‖s‖²；系統抽樣互補隨機變數 ζ，使得方差補齊：
    Var(etotal) = Var(e) + Var(ζ) = Bpub² (公開常數)
    敵手完全無法從雜訊分佈統計中推測私鑰幾何長度。
  • 【優點與缺點】：
    • 優點：標準 LWE 安全，通訊複雜度僅為常數項 O(1)。
    • 缺點：依賴輔助伺服器不與門檻節點串謀的信任假設。
3.5 工具四：雙環模數切換與先遮罩後公開 (Dual-Ring Mask-Then-Open) 流派四：雙環拔噪
  • 【工具定義】： 將質數模數 q 上的密文切換至 2 的冪次整除環 η = p · Φ，利用兩組相關秘密遮罩 (⟨r⟩η, ⟨r⟩Φ) 在兩輪線上交互內安全拔除雜訊。
  • 【運作過程】：
    ① Round 1 (Masked Opening)：各方廣播被均勻隨機遮罩保護的數值：
    v = (b − ⟨a, s⟩ + r) mod η
    由於 r 全環隨機，數值 v 不洩漏任何私鑰資訊；在此階段直接拔除低位雜訊。
    ② Round 2 (Unmasking)：各方廣播第二環遮罩 ⟨r⟩Φ，聚合器相減後直接取得乾淨的放大明文 Φ · m，除以常數 Φ 即完成解密。
  • 【優點與缺點】：
    • 優點：無模數膨脹，通訊極短（每方僅 100~128 bits），達到亞毫秒級速度。
    • 缺點：需要 2 輪線上通訊。

4.1 主動惡意威脅模型與防禦目標 (Active Byzantine Threats) 主動攻擊態勢

在主動惡意環境中，作弊節點會蓄意偏離協定流程，常見攻擊手段包括：提交畸形非三元私鑰以引發運算溢位、在部分解密中注入超額雜訊誘發錯解攻擊（Fault Attack）、篡改部分解密數值以污染最終明文輸出。 防禦的核心武器是零知識證明（Zero-Knowledge Proofs, ZKP）：節點在發布訊息時，必須向全體成員證明其私鑰與運算嚴格守法，且完全不洩漏任何私鑰數據。

4.2 工具一：晶格非交互式零知識證明與拒絕取樣 (Lattice NIZK & Rejection Sampling) 零知識證明核心
  • 【工具定義】： 基於 Lyubashevsky 架構的晶格 Fiat-Shamir NIZK。證明者欲證明自己知曉滿足代數關係 C = A · s mod q 且範數極小 ‖s‖∞ ≤ 1 的秘密向量 s。
  • 【運作過程：Σ-協定、Fiat-Shamir 雜湊與拒絕取樣】：
    ① 承諾 (Commit)：抽樣高斯掩蔽向量 y ← Dσn，計算承諾 T = A · y mod q。
    ② 挑戰 (Challenge)：利用密碼學雜湊函數計算非交互式挑戰 ch = H(A, C, T)。
    ③ 響應與拒絕取樣 (Response & Rejection Sampling)：計算候選回應 z = y + ch · s。 關鍵機制：若直接公開 z，其高斯中心偏向私鑰項 ch · s，攻擊者能藉由統計平均推導出私鑰輪廓！ 因此證明者以機率 min(1, Dσ(z) / (M · Dσ, ch·s(z))) 決定接受或丟棄重抽。 通過發布的 z 其分佈與私鑰 s 嚴格統計獨立，達成完美零知識性！
    ④ 驗證 (Verify)：驗證者檢查 ‖z‖∞ ≤ 邊界 且 A · z − ch · C ≡ T (mod q)。
  • 【優點與缺點】：
    • 優點：抗量子計算攻擊，單輪非交互，具備嚴格統計零知識性。
    • 缺點：需要多次拒絕取樣重抽（可能需嘗試數次），且證明向量尺寸相對較大。

  • 【運作過程：跨 RNS 通道無繞回商數約束】：
    ① 當私鑰被延伸至大模數 RNS 的各個大質數通道 qj 時，為了防止惡意節點在各通道發布彼此矛盾的偽造私鑰，構造多項式整除商數約束：
    sqj = sp + p · kj, 約束商數範數 ‖kj‖∞ ≪ qj

    • 優點：零代數鬆弛，可跨多條質數通道鎖定一致性。

  • 【工具定義】： 將完整大模數 Q 上的同態商數驗證公式，全數降維投射至單一 60-bit 基準質數通道 KQ = q₁；並設計基於佇列的廣度優先搜尋（BFS）二分批次檢驗演算法。

  • 【優點與缺點】：
    • 優點：常態下驗證延遲幾乎為零；少數惡意作弊時可在對數輪內快速抓鬼，徹底破除線性瓶頸。

背景知識 (六) — 威脅模型與正式安全概念：IND-CPA/CCA2、CPAD、FuncCPA 與 UC 安全

配合 5 大架構與流程圖解，深入解析不可區分性階層、同態可塑性衝突、半誠實與惡意界限、解密預言機防禦、電路隱私與 UC 模擬安全
6.1 密碼學經典不可區分性安全階層：IND-CPA、IND-CCA1 與 IND-CCA2 密碼學階層基石

在現代公鑰密碼學中，安全性透過攻擊者（Adversary）與挑戰者（Challenger）之間的不可區分性博弈遊戲（Indistinguishability Game）嚴格定義。依據敵手獲得的「預言機權限」，安全強度呈現遞增階梯：

  • 【階層一：選擇明文攻擊不可區分性 (IND-CPA)】：
    • 【定義】：敵手可任意選取明文並獲得對應密文（在公鑰體系中，敵手持有公鑰可自行加密，等價於擁有無限次加密預言機 𝒪Enc 存取權）。
    • 【博弈流程】：敵手選定兩條等長明文 (m₀, m₁) 發送給挑戰者；挑戰者隨機均勻拋幣 b ∈ {0, 1}，回傳挑戰密文 c* = Enc(pk, mb)。敵手最終輸出猜測 b'。
    • 【安全條件】：若任何多項式時間敵手的猜對優勢滿足不可忽略條件 |Pr[b' = b] − 1/2| ≤ negl(λ)，則稱該方案具備 IND-CPA 安全性。
    • 【同態加密現狀】：標準的 LWE / RLWE / CKKS / BGV 方案天生完全滿足 IND-CPA 安全性（基於 LWE 決策型難題）。
  • 【階層二：非適應性選擇密文攻擊 (IND-CCA1 / Lunchtime Attack)】：
    • 【定義】：又稱「午餐時間攻擊」。敵手在獲得挑戰密文 c* 之前，被允許無限制次數向真實解密預言機 𝒪Dec 遞交任意密文並索取明文回傳值。
    • 【關鍵限制】：一旦挑戰者發布了挑戰密文 c*，解密預言機立即永久切斷！敵手後續只能憑藉此前獲得的資訊進行猜測。
  • 【階層三：適應性選擇密文攻擊 (IND-CCA2 / Full Adaptive CCA)】：
    • 【定義】：公鑰加密的最高黃金標準。敵手在收到挑戰密文 c* 之後，依然可以繼續調用解密預言機 𝒪Dec。
    • 【唯一博弈約束】：敵手僅被禁止直接將挑戰密文 c* 原封不動遞交給解密預言機（否則答案顯而易見），但允許遞交任何與 c* 不同的衍生密文 c' ≠ c*！
  • 【核心衝突定理：為什麼任何全同態加密 (FHE) 在數學上絕不可能達到 IND-CCA2？】：
    • 代數本質衝突：全同態加密的本質特徵在於密文具備可塑性（Homomorphic Malleability）——任何人持有公鑰都能在不解密的前提下，透過同態加法將密文運算為 c' = c* ⊕ Enc(1)。
    • 秒殺攻擊通道：敵手取得挑戰密文 c* = Enc(mb) 後，直接計算 c' = c* ⊕ Enc(1)。此時 c' ≠ c* 完全合法！敵手將 c' 遞交解密預言機，獲得回傳明文 m' = mb + 1，接著計算 m' − 1 = mb，直接以 100% 機率破譯 b！
    • 架構解決之道：因為純 FHE 絕無可能達到 CCA2，在多方協同或雲端計算情境下，密碼學界發展出專屬防線——門檻分散式解密（Threshold Decryption）配合 CPAD 雜訊隔離、MPC Rounding 或零知識證明 (ZKP)，切斷敵手藉由解密回傳值探測秘密的通道！

6.2 分散式密碼學威脅模型全景矩陣 (Threat Models Landscape) 系統信任邊界

在門檻全同態加密（ThFHE）中，密鑰由 N 個節點共同持有。分散式協議的安全性取決於敵手對節點的腐化能力：

  • 【半誠實模型 (Semi-Honest / Honest-but-Curious / Passive)】：
    • 【定義】：受腐化節點忠實按照協議規定的演算法執行運算、發送訊息，絕不竄改或捏造封包，但會暗中儲存所有接收到的協議副本，試圖推導出其他節點的私鑰或明文隱私。
    • 【防禦重點】：依靠秘密分享的資訊理論隱私（完美保密性）與 PRF 隨機遮罩即可抵禦。
  • 【主動惡意模型 (Malicious / Byzantine / Active)】：
    • 【定義】：受腐化節點由全能敵手控制，可任意偏離協議執行：蓄意注入偽造的金鑰、故意回傳帶有毒化雜訊的解密份額、掉包密文，甚至靜默離線拒絕服務。
    • 【防禦重點】：必須引入零知識證明（NIZK）、代數承諾（Commitment）或 Reed-Solomon 糾錯解碼，強制節點自證合法性。
  • 【誠實多數 (Honest Majority) vs. 任意信任 (Anytrust / N−1 Malicious)】：
    • 誠實多數 (t < N/2)：假設全體節點中誠實者嚴格過半。優點是架構簡潔、通訊極快。
    • 不誠實多數 / Anytrust (t = N − 1)：密碼學最嚴苛標準。允許至多 N − 1 個節點惡意串謀勾結，只要全網絡中僅剩 1 位誠實節點，明文隱私仍保證 100% 固若金湯！
6.3 CPAD：主動解密預言機私鑰探測防禦 (Chosen-Plaintext with Decryption Oracle) 邊界攻擊防線

在門檻解密服務中，惡意客戶端若能重複向伺服器提交精心構造的特異密文並取得解密結果，該解密服務即等價於一個「解密預言機（Decryption Oracle）」。CPAD 安全性保證即使存在此解密預言機，敵手也無法探測出私鑰分量：

  • 【CPAD 臨界探測攻擊機制】：
    ① 攻擊流程：敵手構造一組特殊密文，將其解密相位刻意推向捨入臨界判定半徑 Δ/2（如 phase ≈ Δ/2 − a · s）。若私鑰分量為正，相位未溢位，解密回傳明文 0；若私鑰分量為負，相位溢位至相鄰區間，回傳明文 1！敵手藉由回傳的 0 或 1 即可逐位榨取私鑰資訊。
    ② 防禦流程：門檻解密端在發布結果前，注入比原始雜訊大 2λ 倍的統計洪水雜訊（Smudging），或在 MPC 算術黑盒內部直接完成捨入截斷，使回傳分佈與私鑰的統計距離滿足 SD ≤ 2−λ，徹底截斷探測通道！
  • 【優點與缺點】：
    • 優點：徹底封死主動探測私鑰的側信道。
    • 缺點：需要額外增加模數寬裕空間或採用 MPC 查表輪數。
🔢 具體算式範例：CPAD 臨界探測攻擊演算

設模數 q = 100，縮放步距 Δ = 20，臨界容許半徑為 Δ/2 = 10。
未知私鑰分量 s₁ ∈ {−1, +1}。
敵手構造明文為 0 的密文，調整雜訊至 e = 9，測試基底設為 a₁ = +2。解密相位為 phase = 9 − a₁ · s₁：
• 若真實私鑰 s₁ = +1 ⟹ phase = 9 − 2·(1) = 7 < 10 ⟹ 捨入回傳 明文 0（解密成功）。
• 若真實私鑰 s₁ = −1 ⟹ phase = 9 − 2·(−1) = 11 > 10 ⟹ 捨入回傳 明文 1（解密溢位錯誤）。
敵手僅憑觀察回傳值是 0 還是 1，花費 1 次查詢就 100% 確定了私鑰 s₁ 的真實正負號！

6.4 IND-FuncCPA：電路隱私與專利演算法保護 (Circuit Privacy) 計算拓樸保護

在雲端機器學習推論服務中，伺服器投入了高昂研發成本構建神經網路模型。電路隱私保證解密端無法反向推導出伺服器的模型結構：

  • 【工具定義：函數隱私 (IND-FuncCPA / Circuit Privacy)】： 對於任意兩個計算不同評估電路 C₁ 與 C₂、但產出完全相同輸出結果（即 C₁(m) = C₂(m)）的同態計算過程，任何解密方獲得的最終密文分佈在統計上完全不可區分。
  • 【雜訊指紋洩漏與零密文重隨機化防禦】：
    • 洩漏機制：同態相乘會使密文雜訊隨乘法深度與拓樸幾何幾何級膨脹。若伺服器直接將計算後的密文發給客戶端解密，客戶端透過測量解密相位中殘留的雜訊大小與協方差矩陣，就能如同分析「聲學指紋」般反推出模型深度與神經網路權重！
    • 重隨機化防禦 (Rerandomization)：在完成電路求值後，伺服器在密文上疊加一個加密明文為 0 的獨立全新同態密文：
    cfinal = ceval + Czero mod Q
    透過注入充分大標準差的高斯雜訊，將舊運算路徑遺留的細微雜訊特徵完全沖刷淹沒，達成統計意義上的電路隱私！
6.5 通用可組合性 (UC, Universal Composability) 模擬安全框架 黃金模組安全

在複雜分散式系統（如區塊鏈、跨雲端安全多方計算）中，協議往往與無數其他未知網路應用同時運行。Ran Canetti 提出的通用可組合性（UC Framework）是密碼學中最高規格的安全證明典範：

  • 【工具定義：UC 模擬安全範式 (Simulation-Based Security)】： 安全性透過對比兩個世界的行為來嚴密定義：
    • 真實世界 (Real World)：各節點執行實體通訊協議 Π，其中部分節點受真實敵手 𝒜 腐化，可能作弊或窺探訊息。
    • 理想世界 (Ideal World)：不存在實體通訊，所有節點將原始明文直接輸入給一個絕對誠實的理想算術黑盒功能 ℱABB（Arithmetic Black Box）。黑盒在內部完成計算並將正確結果回傳給各方。
  • 【模擬器構造 (Simulator 𝒮) 與環境無差別性】：
    • 【定義】：若對於真實世界中的任何敵手 𝒜，均存在一個理想世界中的多項式時間模擬器 𝒮，使得任意外部觀察者環境（Environment 𝒵）無法分辨它究竟是與「真實世界協定」交互、抑或是與「理想功能黑盒 + 模擬器」交互：
    EXECΠ, 𝒜, 𝒵 ≈ EXECℱABB, 𝒮, 𝒵

    • 【可組合性定理】：若協定在 UC 框架下被證明安全，則該協定可以作為黑盒模組任意嵌套進任何複雜系統、在任意網路延遲下無限次並行調用，其安全性絕對不會退化！

6.1 密碼學系統評測的核心理念：同軌公平基準 (Fair Apples-to-Apples Evaluation) 基準評測哲學

在分散式同態密碼學領域，評估一套方案的優劣不能僅看單一維度： 有些演算法單機運算極快，但線上通訊需要多輪來回握手，在廣域網路（WAN）下延遲暴增；有些方案在半誠實環境下表現優異，但加入主動防禦的零知識證明後計算開銷激增百倍。 同軌公平基準（Apples-to-Apples Evaluation）將運算延遲、通訊輪數、頻寬開銷與安全良率置於統一控制變因下進行多維度綜合檢驗。

6.2 全域實驗控制參數深度解析 (Benchmark Control Parameters) 控制變因解析
  • 【參數一：參與方總數量 (N = 10 ~ 1000)】：
    • 定義與考驗目標：參與分散式金鑰分發與門檻解密的實體總數。主要考驗演算法的時間與空間擴展性（Scalability）。
    • 擴展性層級：常數複雜度 O(1)（Shamir 分享份額固定）、對數複雜度 O(log N)（二分批次快篩）、線性複雜度 O(N)（逐一 ZKP 驗證）。
  • 【參數二：隨機惡意節點比例 (0% ~ 49%)】：
    • 定義與考驗目標：系統中遭受敵手入侵並主動發動作弊的節點百分比（最高近半數節點腐敗）。
    • 檢驗重點：半誠實方案在作弊注入時是否發生明文損毀，以及主動防禦方案是否能做到 100% 成功攔截並剃除作弊節點。
  • 【參數三：四大代表性主動攻擊模式 (Attack Scenarios)】：
    ① 超標雜訊淹沒攻擊 (Excessive Noise)：注入大於容許上界的雜訊，企圖突破臨界邊界 Δ/2 製造解密進位溢位。
    ② 非三元畸形私鑰攻擊 (Malformed Key)：金鑰係數超出 {−1, 0, 1} 約束，檢驗範數約束機制。
    ③ 解密份額與 MAC 竄改攻擊 (Corrupted Share)：惡意偏移部分解密數值，企圖污染最終輸出明文。
    ④ 聚合伺服器欺詐 (Equivocating Aggregator)：中心伺服器向不同成員發布相斥的多項式視圖。
  • 【參數四：明文空間大小 (T ∈ {2, 16, 256, 1024})】：
    • 定義與考驗目標：明文數值空間容量。縮放步距為 Δ = ⌊Q / T⌉。
    • 極限挑戰：當 T 由 2 擴展至 1024 時，格點安全間距縮小 512 倍，極度考驗演算法在雜訊控制與模數精度間的餘裕設計。
6.3 七大計時實測階段全流程剖析 (The 7 Benchmark Stages) 端到端計時鏈
  • Stage 1: Setup（公開參數初始化與預處理）：生成共用隨機字串（CRS）、RNS 質數基線通道、以及 MPC 查表所需的三元組。
  • Stage 2: KeyGen（門檻分散式金鑰生成）：協同生成私鑰份額、集體公鑰 PK、重線性化金鑰 RLK、以及 ZKP 註冊承諾。
  • Stage 3: Encrypt（明文編碼與密文注入）：將輸入數值乘以 Δ，注入初始高斯雜訊，生成標準密文 ct = (a, b)。
  • Stage 4: Eval (Add/Mul)（同態運算與電路評估）：在密文上執行同態加乘與重線性化，測試密文運算吞吐量。
  • Stage 5: PartDec（本地部分解密與雜訊處理）：各節點計算內積相位，並執行統計雜訊淹沒、MPC 內部捨入或雙環遮罩。
  • Stage 6: ZKP/MAC Verify（主動防禦驗證與抓鬼篩檢）：驗證 Fiat-Shamir NIZK、檢查 MAC 標籤或執行 BFS 二分快篩抓出作弊節點。
  • Stage 7: Combine（最終明文聚合與解密輸出）：收集合法份額求和或插值，捨入還原明文並檢驗結果正確性。
6.4 競技場圖表解讀指南與探索建議 (Reading Arena Charts & Metrics) 實測數據判讀
  • 階段延遲堆疊直方圖 (Latency Breakdown Stacked Bar)： 以 7 種顏色堆疊展示 7 階段耗時，直觀揭示運算瓶頸：例如某方案瓶頸在 Stage 5 的多輪查表，而另一方案瓶頸在 Stage 6 的線性驗證。
  • 通訊輪數與 WAN 廣域網路敏感度 (Round Complexity)： 單輪非交互方案（1 輪）在廣域網路（100ms 延遲）下依然秒級響應，而多輪方案（5 輪）則會因來回握手累積較大通訊等待。
  • 主動防禦攔截日誌 (Security Defense Interception Log)： 即時顯示被抓出的作弊節點編號、攻擊手法特徵、數學違規檢驗結果與剔除耗時。
